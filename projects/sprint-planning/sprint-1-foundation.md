# Sprint 1: Foundation

## Goal

Set up the core local data model, filesystem access, and app skeleton needed for the rest of the product.

## Scope

- Scaffold backend and frontend app structure if missing
- Define core entities: Manga, Chapter, Translation, Translator
- Add local library path configuration
- Add filesystem scanning for manga folders and chapter image folders
- Add fixture-based tests for library discovery

## Deliverables

- Backend entrypoint running locally
- Frontend shell with navigation placeholders
- Basic library scan returning manga metadata and chapter image lists
- Test fixtures for sample manga folders

## Exit Criteria

- App can start locally
- A sample library folder can be scanned without network access
- Tests cover the first filesystem parsing path
