# Sprint 3: Reader Experience

## Goal

Build the reading flow and persistence users need for daily use.

## Scope

- Page-by-page reader
- Continuous scrolling mode
- Keyboard navigation
- Remember last read page locally
- Switch language and translator on the fly

## Deliverables

- Reader page with navigation controls
- Local progress persistence
- Variant switching UI
- Tests for progress and selection behavior

## Exit Criteria

- A user can open a chapter and continue reading from the last page
- Reader supports both paging and scrolling
- Variant switching works without losing progress
