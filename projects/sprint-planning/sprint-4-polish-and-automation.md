# Sprint 4: Polish and Automation

## Goal

Improve discoverability, usability, and maintenance without changing the offline-only constraint.

## Scope

- Search manga and chapters
- Reading history
- Favorites
- Auto-detect new chapters from folders
- Dark/light theme

## Deliverables

- Search and sorting helpers
- History and favorites persistence
- Folder change detection or rescanning flow
- Theme toggle
- Regression tests for the optional enhancements

## Exit Criteria

- Library is easy to browse and resume
- New local chapters can be detected or refreshed
- UI remains fully local and offline
