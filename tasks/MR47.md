# MR47: Minio Client Module

## Title

Create a Minio client module to connect to the Minio S3-compatible storage.

## Description

The docker-compose.yml already defines a Minio service (`minio/minio:latest`) with credentials `minioadmin/minioadmin` and a bucket `manga-pages`. The backend has env vars `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET` configured. Create a NestJS module that initializes a Minio client and provides it to the rest of the app via dependency injection.

## Requirement

- Install the `minio` npm package in the backend
- Create `backend/src/modules/file/minio-client.ts` that reads env config and creates a Minio client instance
- Verify the bucket `manga-pages` exists on startup (create it if missing)
- Export a `MinioClient` token/provider so services can inject it
- Register the module in `app.module.ts` as a global module or import it where needed

## Acceptance Criteria

- [ ] `minio` npm package is installed
- [ ] Minio client is initialized from env vars at app startup
- [ ] Bucket auto-creation on startup works (bucket is created if absent)
- [ ] Minio client is injectable into other providers (e.g., `@Inject('MINIO_CLIENT')`)
- [ ] Module is registered in the app
