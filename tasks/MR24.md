# MR24: Continuous Scroll Reader

## Title
Add a continuous scroll reading mode.

## Description
Provide a webtoon-style continuous scroll mode as an alternative to page-by-page reading for readers who prefer vertical flow.

## Requirement
- Support scrolling through chapter images in a single flow
- Keep the scroll mode readable on long chapters
- Reuse the same local chapter image source as page mode
- Preserve a smooth experience with many images

## Acceptance Criteria
- [ ] Readers can switch to a continuous scroll mode
- [ ] Chapter images appear in a vertical reading flow
- [ ] Long chapters remain usable in scroll mode
- [ ] Scroll mode uses the same chapter content as page mode

## Estimate Point
5
