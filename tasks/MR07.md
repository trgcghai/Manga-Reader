# MR07: Filesystem Manga Scanner

## Title
Build filesystem scanner for manga library root.

## Description
Implement the endpoint that scans the inputed path, detects direct children inside it and returns them.

## Requirement
- Read manga folders from a configured local path
- Ignore non-directory entries
- Support fixture-based tests for sample manga library structures
- Return a stable list of detected manga folders
- Keep all behavior offline-only and local filesystem based

## Acceptance Criteria
- [ ] Scanner returns detected childrens (images) from a inputed path from client
- [ ] Scanner works with fixture folders in tests
- [ ] Missing or unreadable paths fail gracefully
- [ ] Scanner output can be consumed by the backend API
