# MR11: Manga CRUD Create and List

## Title
Create and list manga entries in the admin panel.

## Description
Build the manga creation form and list view so an admin can add new manga records and browse existing entries from the local content library.

## Requirement
- Provide a manga create form in the admin UI
- Expose API endpoints to create and list manga
- Validate required manga fields before saving
- Show newly created manga in the list without manual refresh

## Acceptance Criteria
- [ ] Admin can create a manga record from the UI
- [ ] Admin can see all manga records in a list view
- [ ] Validation prevents saving incomplete manga data
- [ ] The create flow returns the newly created manga in the list

5
