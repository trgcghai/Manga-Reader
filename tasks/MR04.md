# MR04: MongoDB Setup & Mongoose Configuration

## Description
Set up MongoDB connection in the NestJS backend using Mongoose, configure the connection module, and verify connectivity with the Docker Compose MongoDB service.

## Requirements
- Install `@nestjs/mongoose`, `mongoose`
- Configure `MongooseModule.forRoot()` with environment variables:
  - `MONGODB_URI` (e.g., `mongodb://manga:manga@mongodb:27017/manga_reader?authSource=admin`)
- Create a `MongoModule` or integrate into `AppModule`
- Add connection health check
- Configure schema loading path
- Works with Docker Compose `mongodb` service (port 27017)

## Acceptance Criteria
- [ ] Backend connects to MongoDB on startup
- [ ] Connection uses `MONGODB_URI` environment variable
- [ ] `MongooseModule` is properly registered in `AppModule`
- [ ] Health check endpoint verifies MongoDB connectivity
- [ ] Works with `docker compose up mongodb`
- [ ] Connection options (retry, auth) are properly configured
