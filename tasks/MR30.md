# MR30: Theme Toggle

## Title
Add a persistent dark and light theme toggle.

## Description
Implement a theme switcher with saved preference so readers can choose a light or dark experience without disrupting the reading flow.

## Requirement
- Provide a dark/light theme toggle
- Persist the chosen theme preference
- Apply the theme across the app shell and reader pages
- Keep reader image display readable in both themes

## Acceptance Criteria
- [ ] Readers can switch between dark and light themes
- [ ] The selected theme persists after reload
- [ ] The theme applies consistently across app pages
- [ ] Reader images remain visible in both themes

4
