# MR33: Mobile and Accessibility Polish

## Title
Improve mobile responsiveness and accessibility basics.

## Description
Polish the UI for smaller screens and add baseline accessibility improvements such as labels and focus handling.

## Requirement
- Improve layouts for mobile screens
- Add useful aria labels where needed
- Ensure keyboard focus remains visible
- Keep interactive controls accessible

## Acceptance Criteria
- [ ] Key screens work on mobile viewport sizes
- [ ] Interactive elements have appropriate labels
- [ ] Keyboard focus is visible and usable
- [ ] Basic accessibility checks pass for the polished UI
