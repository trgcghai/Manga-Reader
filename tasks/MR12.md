# MR12: Manga CRUD Edit and Delete

## Title
Edit and delete manga records.

## Description
Add update and delete actions for manga so an admin can maintain manga metadata after the initial create flow.

## Requirement
- Provide manga edit form and save action
- Provide manga delete action with confirmation
- Update API support for edit and delete operations
- Keep the list view in sync after changes

## Acceptance Criteria
- [ ] Admin can edit an existing manga record
- [ ] Admin can delete a manga record after confirming the action
- [ ] Updated manga data is reflected in the list view
- [ ] Deleted manga no longer appears in the admin list

3
