# MR46: Searchable Translator Select

## Title
Replace hardcoded translator dropdown with a searchable combobox.

## Description
Both `AddChapterDialog.tsx` and `AddTranslationDialog.tsx` call `useTranslatorList(1, 100)` — a hardcoded fetch that breaks once there are more than 100 translators. The `<Select>` component is not searchable. Replace it with a searchable combobox that queries the backend by name as the user types.

## Requirement
- Replace `<Select>` with a searchable combobox (using shadcn Command + Popover or similar)
- Fix the hardcoded pagination: fetch translators by search query instead of loading all
- The backend `/translators?search=` and the hook `useTranslatorList(page, limit, search)` already support search — only the UI needs to change
- Apply to both `AddChapterDialog.tsx` and `AddTranslationDialog.tsx`
- Add `command.tsx` + `popover.tsx` shadcn components if not present

## Acceptance Criteria
- [ ] Translator field is a searchable combobox, not a plain select
- [ ] Typing in the combobox searches translators by name via the API
- [ ] Works correctly with more than 100 translators
- [ ] Applied in both AddChapterDialog and AddTranslationDialog
- [ ] Existing form validation (translatorId required) still works
