# MR46: Searchable Translator Combobox

## Title
Replace hardcoded translator `<Select>` with a searchable combobox that queries the backend by name.

## Description
Both `AddChapterDialog.tsx` and `AddTranslationDialog.tsx` call `useTranslatorList(1, 100)` — a hardcoded fetch that breaks once there are more than 100 translators. The `<Select>` component is not searchable, so users must scroll through an unsorted list. Replace it with a shared `TranslatorCombobox` component using shadcn `Command` + `Popover` that debounce-searches the backend by name.

## Requirement

### 1. Add missing shadcn component: `popover.tsx`
- `command.tsx` (cmdk) already exists in `frontend/src/components/ui/`
- `popover.tsx` does NOT exist — must be installed from shadcn registry
- Run `npx shadcn add popover` to install it (or hand-write it matching the existing shadcn style)

### 2. Create shared `TranslatorCombobox` component
Location: `frontend/src/components/translator/TranslatorCombobox.tsx` (new file)

#### Props interface
```typescript
interface TranslatorComboboxProps {
  value: number                  // selected translator id (0 = none)
  onChange: (id: number) => void // called when user selects a translator
  invalid?: boolean              // aria-invalid flag from form field meta
  id?: string                    // forwarded to trigger for label htmlFor
  placeholder?: string           // default: "Search translator..."
}
```

#### Internal state & behavior
- **Open state**: `boolean` controlled by Popover open/close
- **Search input**: `string` bound to `<CommandInput>` inside the popover
- **Debounced search**: 300ms debounce on the search input value
- **Data fetching**: `useTranslatorList(1, 50, debouncedSearch)` — page size 50 is sufficient for search results
- **No search text**: When search is empty, show initial results (e.g. first 50 translators). This avoids an empty popover on first open.
- **Loading state**: `<CommandLoading>` (or a small spinner) while query is fetching — note: the existing `command.tsx` does NOT export `CommandLoading`. Either add a spinner manually or add the export to `command.tsx`. Prefer adding a spinner inside the combobox itself (e.g. a `<Loader2 className="animate-spin" />` inside CommandList).
- **Empty state**: `<CommandEmpty>` shows "No translators found." when the search yields no results.
- **Error state**: If `isError` is true from the query, show "Failed to load translators." inside the popover and allow retry by closing/reopening.
- **Selection**: `<CommandItem>` for each translator; clicking calls `onChange(tr.id)` and closes the popover
- **Display**: When a translator is selected (`value > 0`), the trigger shows the translator name. How to get the name? Options:
  - Store selected translator name in a local state (set it when user selects)
  - Fetch by ID: `useTranslator(value)` — adds another query but ensures name is fresh
  - **Recommendation**: Keep a local `selectedName: string` state. Set it when user selects an item. Clear it when `value` changes to 0 externally.
- **Keyboard navigation**: cmdk provides built-in arrow key + enter support. Ensure `Popover.Content` doesn't trap focus incorrectly when pressing Escape.

#### Component structure (pseudocode)
```
<Popover open={open} onOpenChange={setOpen}>
  <PopoverTrigger asChild>
    <Button variant="outline" role="combobox" aria-expanded={open}>
      {selectedName || "Select translator..."}
      <ChevronsUpDown />
    </Button>
  </PopoverTrigger>
  <PopoverContent>
    <Command shouldFilter={false}>
      <CommandInput placeholder="Search translator..." value={search} onValueChange={setSearch} />
      <CommandList>
        {isLoading && <Loader2 className="animate-spin" />}
        {isError && <p>Failed to load translators.</p>}
        {!isLoading && !isError && data.data.length === 0 && (
          <CommandEmpty>No translators found.</CommandEmpty>
        )}
        <CommandGroup>
          {data?.data.map((tr) => (
            <CommandItem key={tr.id} value={String(tr.id)} onSelect={() => { onChange(tr.id); setSelectedName(tr.name); setOpen(false); }}>
              <Check className={value === tr.id ? "opacity-100" : "opacity-0"} />
              {tr.name}
            </CommandItem>
          ))}
        </CommandGroup>
      </CommandList>
    </Command>
  </PopoverContent>
</Popover>
```
