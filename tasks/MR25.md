# MR25: Translation Switching UI

## Title
Switch between available translations in the reader.

## Description
Add language and translator dropdowns so readers can switch between translation variants while staying in the same chapter.

## Requirement
- Show translation options in the reader UI
- Let readers choose language and translator combinations
- Keep the selected translation visible and understandable
- Preserve the current reading position when switching where possible

## Acceptance Criteria
- [ ] Readers can see available translation options
- [ ] Readers can switch to a different language or translator
- [ ] The active translation is clearly indicated in the UI
- [ ] Switching translations keeps the reader usable at the current position

## Estimate Point
4
