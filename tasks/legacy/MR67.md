# MR67: Frontend — Reading Mode Keyboard Navigation

## Title

Implement keyboard arrow key navigation for page and scroll reading modes, chapter prev/next navigation, and overlay chapter navigation buttons.

## Description

The reader needs keyboard controls for fluid navigation. Two reading modes have distinct keyboard behaviors. This task covers the keyboard handler, chapter navigation context, and chapter nav buttons. Progress persistence is handled separately in MR68.

### Existing context

- `frontend/src/stores/rootStore.ts` exports `useReaderStore` (zustand) with:
  - State: `currentTranslation: TranslationDetailResponse | null`, `currentChapter: { id, number, title?, mangaId, mangaTitle } | null`, `currentPage: number`, `totalPages: number`, `readingMode: 'page' | 'scroll'`, `displayMode: 'single' | 'double'`
  - Actions: `setCurrentTranslation(t)`, `setCurrentPage(n)`, `setTotalPages(n)`, `setReadingMode(mode)`, `setDisplayMode(mode)`, `nextPage()`, `prevPage()`, `reset()`
- `frontend/src/services/api/mangaApi.ts` exports:
  - `getManga(id: number, include?: string): Promise<MangaResponse | MangaDetailResponse>` — e.g., `getManga(1, 'chapters,translations')` returns `MangaDetailResponse` with `chapters: ChapterDetail[]`
  - `getTranslation(id: number): Promise<TranslationDetailResponse>` — returns a single translation with `url` and `chapter.manga.id`
  - `ChapterDetail`: `{ id, number, title?, releaseDate?, note?, translations: TranslationDetail[] }`
- `frontend/src/types/translation.ts` defines `TranslationDetailResponse` with `chapter: { id, number, title?, manga: { id, title } }` and `url: string`
- Import alias `#/` maps to `frontend/src/`
- `frontend/src/routes/_reader/reader.$translationId.tsx` is the reader page:
  - Reads `translationId` from `useParams({ from: '/_reader/reader/$translationId' })`
  - Uses `useTranslation(id)` from `#/hooks/useManga` to fetch `TranslationDetailResponse`
  - Uses `useReaderPages(data?.url)` from `#/hooks/useReaderPages` to download CBZ and return object URLs (`{ pages, isLoading, error }`)
  - Reads `currentPage`, `displayMode` from `useReaderStore` (does NOT yet read `readingMode`)
  - Destructures `nextPage`, `prevPage` from store
  - Has loading/error skeleton states for both translation and pages
  - Does NOT yet import `useNavigate` from `@tanstack/react-router`
- `frontend/src/routes/_reader.tsx` is the reader layout — renders `<Outlet />` in a dark container (`bg-zinc-950`)
- `frontend/src/hooks/useDebounce.ts` already exists (wraps `lodash/debounce`, returns debounced value)
- Existing patterns: hooks use `@tanstack/react-query` (`useQuery`, `useMutation`), components use Radix UI + `lucide-react` icons
- PageViewer (`frontend/src/components/reader/PageViewer.tsx`) accepts `{ pages, displayMode, currentPage, onNextPage, onPrevPage }` — currently only supports page mode (single/double), NOT scroll mode

### Keyboard navigation rules

**Page mode:**
| Key | Action |
|---|---|
| ArrowLeft | `prevPage()` from store. If `currentPage === 0`, navigate to previous chapter's last page |
| ArrowRight | `nextPage()` from store. If `currentPage === totalPages - 1`, navigate to next chapter's first page |
| ArrowUp | Navigate to previous chapter (fetch its first translation and navigate to its route) |
| ArrowDown | Navigate to next chapter (fetch its first translation and navigate to its route) |

**Scroll mode:**
| Key | Action |
|---|---|
| ArrowUp | Scroll the reader container by `window.innerHeight` pixels up, smoothly |
| ArrowDown | Scroll the reader container by `window.innerHeight` pixels down, smoothly |
| ArrowLeft | Navigate to previous chapter (same as page mode) |
| ArrowRight | Navigate to next chapter (same as page mode) |

### Changes needed

1. **Chapter navigation context** — In `frontend/src/routes/_reader/reader.$translationId.tsx`:
   - Import `useManga` from `#/hooks/useManga` and `useNavigate` from `@tanstack/react-router`
   - After `useTranslation(id)` resolves, get `mangaId` from `data?.chapter.manga.id`
   - Call `useManga(mangaId, { include: 'chapters,translations' })` to fetch `MangaDetailResponse` with `chapters`
   - Build a sorted chapter list from `data.chapters` (sorted by `number`)
   - Create helper functions (can be inline or in a separate util like `frontend/src/lib/chapterNav.ts`):
     - `findChapterIndex(chapters: ChapterDetail[], currentChapterId: number): number` — returns index of current chapter in the sorted list, or `-1`
     - `getPrevChapter(chapters: ChapterDetail[], currentChapterId: number): ChapterDetail | null` — returns previous chapter or `null` if on first
     - `getNextChapter(chapters: ChapterDetail[], currentChapterId: number): ChapterDetail | null` — returns next chapter or `null` if on last
     - `getFirstTranslationId(chapter: ChapterDetail): number | null` — returns the first translation's `id`, or `null` if the chapter has no translations
   - Handle edge cases: manga has no chapters, current chapter missing from list, chapter has no translations

2. **Keyboard handler hook** — Create `frontend/src/hooks/useReaderKeyboard.ts`:
   - Signature:
     ```ts
     export function useReaderKeyboard(options: {
       readingMode: 'page' | 'scroll'
       onPrevPage: () => void
       onNextPage: () => void
       onPrevChapter: () => void
       onNextChapter: () => void
       onScrollUp: () => void
       onScrollDown: () => void
       enabled?: boolean
     }): void
     ```
   - Attach `keydown` event listener on `window` inside a `useEffect`
   - Listener logic:
     - Check `event.key` against known keys (`ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`)
     - `event.preventDefault()` for handled keys (to prevent browser default scrolling)
     - Dispatch based on `readingMode`:
       - **Page mode**: `ArrowLeft` → `onPrevPage`, `ArrowRight` → `onNextPage`, `ArrowUp` → `onPrevChapter`, `ArrowDown` → `onNextChapter`
       - **Scroll mode**: `ArrowUp` → `onScrollUp`, `ArrowDown` → `onScrollDown`, `ArrowLeft` → `onPrevChapter`, `ArrowRight` → `onNextChapter`
     - Guard: skip if `event.repeat` is true (ignore held-key repeats)
     - Guard: skip if `enabled` is `false`
   - Detach listener on unmount or when dependencies change
   - Do NOT handle keyboard when focus is inside an `input`/`textarea` (check `(event.target as HTMLElement).tagName`)

3. **Page mode integration** — Wire keyboard into the reader route:
   - In `reader.$translationId.tsx`:
     - `const { currentPage, totalPages, readingMode } = useReaderStore()`
     - `const nextPage = useReaderStore(s => s.nextPage)`, `const prevPage = useReaderStore(s => s.prevPage)`
     - Define chapter navigation callbacks:
       - `handlePrevChapter`: find prev chapter via `getPrevChapter`, if exists and has at least one translation, navigate with `navigate({ to: '/reader/reader/$translationId', params: { translationId: String(getFirstTranslationId(prevChapter)) } })`. If `readingMode === 'page'` and `currentPage === 0`, trigger after boundary navigation falls through.
       - `handleNextChapter`: find next chapter via `getNextChapter`, if exists and has translations, navigate similarly.
     - Call `useReaderKeyboard({ readingMode, onPrevPage, onNextPage, onPrevChapter: handlePrevChapter, onNextChapter: handleNextChapter, onScrollUp, onScrollDown })` with the callbacks
   - At chapter boundaries in page mode, wrap PageViewer's `onPrevPage`/`onNextPage`:
     - `wrappedPrevPage`: if `currentPage <= 0`, call `handlePrevChapter`; otherwise call `prevPage()`
     - `wrappedNextPage`: if `currentPage >= totalPages - 1`, call `handleNextChapter`; otherwise call `nextPage()`
     - Pass these wrapped versions to `PageViewer`

4. **Scroll mode integration** — Wire keyboard into reader:
   - In `reader.$translationId.tsx`:
     - Get a `ref` to the scrollable container via `useRef<HTMLDivElement>(null)`
     - `onScrollUp`: `containerRef.current?.scrollBy({ top: -window.innerHeight, behavior: 'smooth' })`
     - `onScrollDown`: `containerRef.current?.scrollBy({ top: window.innerHeight, behavior: 'smooth' })`
     - Track which page is most visible using an `IntersectionObserver` on each page image:
       - After pages render, observe each `img` element in the scroll container
       - The page with the highest `intersectionRatio` gets its index set via `useReaderStore.getState().setCurrentPage(index)`
       - Use a `useEffect` with `RefObject<HTMLDivElement>` to set up the observer after render
       - Debounce updates to avoid excessive store writes (e.g., update at most every 200ms)
     - Wrap the images in a scrollable `<div ref={containerRef} className="overflow-y-auto h-screen">` (only in scroll mode)

5. **Chapter navigation UI** — Create `frontend/src/components/reader/ChapterNavButtons.tsx`:
   - Props:
     ```ts
     interface ChapterNavButtonsProps {
       onPrevChapter: () => void
       onNextChapter: () => void
       hasPrev: boolean
       hasNext: boolean
     }
     ```
   - Renders two buttons overlaid on left and right edges of the reader:
     - Left button: `<Button variant="ghost" size="icon" onClick={onPrevChapter} disabled={!hasPrev}>` with `<ChevronLeft className="size-8" />` icon from `lucide-react`, positioned with `className="absolute left-4 top-1/2 -translate-y-1/2"`
     - Right button: same with `<ChevronRight />`, positioned `right-4`
   - Buttons are semi-transparent by default (`opacity-30`), become `opacity-100` on hover via `hover:opacity-100 transition-opacity`
   - Hidden (via `className="hidden"`) when both `hasPrev` and `hasNext` are false
   - Container: `<nav className="fixed inset-0 pointer-events-none z-50">`, buttons have `pointer-events-auto`
   - Integrate into reader page: render `<ChapterNavButtons onPrevChapter={handlePrevChapter} onNextChapter={handleNextChapter} hasPrev={!!getPrevChapter(...)} hasNext={!!getNextChapter(...)} />` when pages are loaded
