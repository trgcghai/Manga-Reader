# MR32: UI Loading Empty and Error States

## Title
Refine loading, empty, and error states.

## Description
Improve UI feedback across the app so users see clear loading indicators, empty states, and error handling instead of blank or confusing screens.

## Requirement
- Add loading states where data is being fetched
- Add empty states for missing content
- Add clear error states for failures
- Keep the messages consistent across pages

## Acceptance Criteria
- [ ] Loading states appear during data fetches
- [ ] Empty states appear when no content is available
- [ ] Error states are visible and understandable
- [ ] The feedback pattern is consistent across the app

5
