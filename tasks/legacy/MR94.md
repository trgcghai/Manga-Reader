# MR94: Frontend chapter import dialog and hooks

## Title

Create ImportChaptersDialog UI with hooks, template download, and result display.

## Description

Build the frontend UI for the bulk chapter/translation import feature. Follows the same pattern as the existing `ImportDialog` for mangas. The dialog allows users to upload a ZIP file containing the Excel + organized CBZ files, download a template, and see import results.

### Components

1. **`ImportChaptersDialog`** — A dialog component that:
   - Has a file dropzone accepting `.zip` files only
   - Has a "Download template" button that fetches and downloads the ZIP template (contains Excel + example folder structure)
   - Has an "Import" button that uploads the ZIP to the backend
   - Shows a loading state while importing
   - Shows import results on completion (success count + error details)
   - The results view should show:
     - `{created}/{total}` chapters imported successfully
     - If there are errors: an expandable list showing each error with row number and message

2. **Hooks**:
   - `useImportChapters()` — mutation hook that calls `importChapters(file)` API
   - `useGetChapterImportTemplate()` — query hook that fetches the template blob

### Implementation details

- Place the dialog at: `frontend/src/components/chapter/ImportChaptersDialog.tsx`

### API layer

Add to `frontend/src/services/api/mangaApi.ts`:
```typescript
export async function getChapterImportTemplate(): Promise<Blob> {
  const res = await axiosInstance.get('/mangas/import-chapters-template', {
    responseType: 'blob',
  })
  return res.data
}

export async function importChapters(file: File): Promise<ImportResult> {
  const formData = new FormData()
  formData.append('file', file)
  const res = await axiosInstance.post<ImportResult>(
    '/mangas/import-chapters',
    formData,
    { headers: { 'Content-Type': 'multipart/form-data' } },
  )
  return res.data
}
```

### Integration

- Add an "Import Chapters" button to the manga detail page (`frontend/src/routes/admin/mangas/$id.index.tsx`) in the chapters section header area
- Clicking the button opens the `ImportChaptersDialog`
- After successful import, invalidate the manga detail query to refresh the chapters list

### Edge cases

- Import in progress → disable button, show spinner
- Import completed with errors → show success count and error list (collapsible)
- Import completed with all successes → show success message, auto-close dialog after 2 seconds
- Network error → show error toast
- Template download fails → show error toast
- Dialog close discards the selected file and resets state
