# MR31: Auto-Detect New Chapters

## Title
Detect new chapters automatically.

## Description
Add a scan button or scheduled refresh flow that checks local library folders for new chapters and updates the app when changes are found.

## Requirement
- Provide a manual scan action or refresh flow
- Support detecting newly added chapters from local folders
- Keep detection compatible with the existing scanning logic
- Avoid overly frequent or disruptive refreshes

## Acceptance Criteria
- [ ] Readers or admins can trigger a refresh scan
- [ ] Newly added local chapters are detected
- [ ] The app updates after a successful scan
- [ ] Refresh behavior stays usable on local filesystems

8
