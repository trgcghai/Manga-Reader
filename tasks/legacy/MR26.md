# MR26: Chapter Listing and Image Retrieval API

## Title
Add backend endpoints for chapters and chapter images.

## Description
Expose read-only backend endpoints for fetching a manga's chapters and a chapter's image list so the reader can load data cleanly.

## Requirement
- Provide `GET /manga/:id/chapters`
- Provide `GET /chapter/:id/images`
- Return chapter and image data in a reader-friendly shape
- Keep the endpoints compatible with the local-only app flow

## Acceptance Criteria
- [ ] The backend returns chapters for a manga via `GET /manga/:id/chapters`
- [ ] The backend returns image data for a chapter via `GET /chapter/:id/images`
- [ ] The endpoints support the reader UI without extra client-side guessing
- [ ] The responses are covered by tests or existing API checks
