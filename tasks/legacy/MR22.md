# MR22: Page-by-Page Reader

## Title
Read chapters one page at a time with keyboard navigation.

## Description
Build the main reader experience for page-by-page reading with keyboard controls and click zones for moving through chapter images.

## Requirement
- Render chapter images one page at a time
- Support keyboard navigation between pages
- Support click or tap zones for previous and next page actions
- Keep the reader responsive for local image files

## Acceptance Criteria
- [ ] A chapter opens in page-by-page reader mode
- [ ] Keyboard input moves between pages
- [ ] Click or tap zones navigate between pages
- [ ] The current page is displayed clearly and reliably

8
