# MR65: Frontend — Create Reader Layout and Route

## Title

Create a full-screen reader layout (`/_reader`) that removes header/footer chrome, add the `/reader/$translationId` route with route params, and wire up the API hook to fetch translation data.

## Description

The reader needs a dedicated full-screen view without the standard app header, footer, and max-width container. A new layout group `/_reader` (using TanStack Router's layout route convention) will provide this. The `/reader/$translationId` route lives under this layout and fetches the translation data on entry.

### Changes needed

1. **Reader layout** — Create `frontend/src/routes/_reader.tsx`:
   - Full-screen layout with no header/footer
   - Dark background (or theme-aware)
   - `<Outlet />` for child routes
   - No max-width constraint

2. **Reader page route** — Create `frontend/src/routes/_reader/reader.$translationId.tsx`:
   - Matches `/reader/$translationId`
   - Reads `translationId` from route params via `useParams`
   - Fetches translation data using API hook
   - Renders loading/error/data states
   - Passes translation data to child reader components

3. **API function** — Add `getTranslation(id: number)` to `frontend/src/services/api/mangaApi.ts`:
   - `GET /mangas/translations/${id}`
   - Returns `TranslationDetail` with chapter/manga context

4. **Hook** — Add `useTranslation(id: number)` to `frontend/src/hooks/useManga.ts`:
   - `useQuery` that calls `getTranslation`
   - Query key: `['manga', 'translations', id]`

5. **Regenerate routes** — Run `npm run generate-routes` to update `routeTree.gen.ts`

## Requirement

- Create `/_reader` layout route (full-screen, no header/footer, dark background)
- Create `/reader/$translationId` page route
- Add `getTranslation` API function to `mangaApi.ts`
- Add `useTranslation` hook to `useManga.ts`
- Run `npm run generate-routes`
- `cd frontend && npm run build` passes with 0 errors
