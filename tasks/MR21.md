# MR21: Public Manga Detail Page

## Title
Public manga detail page with chapter list and translation info.

## Description
Create a public-facing manga detail page at `/_app/manga/$mangaId` showing the cover image, full metadata, and an ordered chapter list with translation details (language + translator). This is the landing page after clicking a MangaCard in the library grid. The chapter reader comes in a separate MR.

## Requirements

### Route & Navigation
- New route: `/_app/manga/$mangaId` → file `frontend/src/routes/_app/manga/$id.tsx`
- MangaCard in the library grid wraps in a `<Link>` to `/_app/manga/$mangaId`
- Show a "Back to Library" link/button at the top
- Use existing `useManga(id, { include: 'chapters,translations' })` hook

### Layout
Sidebar layout:
- **Left column**: Cover image (sidebar card style, ~250px wide, with rounded corners and shadow)
- **Right column**:
  - Title (h1, font-serif) + status badge
  - Authors (as badges)
  - Genres (as badges)
  - Description (text block)
  - Alternative titles (comma-separated)
  - Chapter list heading

### Chapter List
- Plain list (no CRUD actions, no collapsible sections)
- Ordered by chapter number ascending (1, 2, 3, ...)
- Each chapter row shows:
  - Chapter number (e.g., "#1")
  - Chapter title (if available)
  - Each translation on its own line: `{Language} by {Translator}`
    - Example: "English by ScanTeamX"
    - Example: "Vietnamese by TeamABC"
- Simple card/divider-based list (not a `<Table>` — more natural for a public page)
- Empty state if no chapters exist

### Loading & Error States
- Loading: skeleton matching the sidebar/chapter layout
- Error: error display with retry button
- Not found (404): "Manga not found" message

### Data
- All data comes from `useManga(id, { include: 'chapters,translations' })` returning `MangaDetailResponse`
- Chapters sorted by `number` ascending (backend already sorts them)
- Translation fields used: `language.name`, `translator.name`, `folderPath` (for future reader linking)

## Acceptance Criteria
- [ ] A public detail page exists at `/_app/manga/$mangaId`
- [ ] Clicking a MangaCard navigates to the detail page
- [ ] Cover image displayed in sidebar style with rounded corners and shadow
- [ ] Full metadata shown: title, status, description, alternative titles, authors, genres
- [ ] Chapter list shows chapter number, title, and all translations with language + translator name
- [ ] Chapters sorted by number ascending
- [ ] Loading, error, and not-found states handled
- [ ] "Back to Library" link returns to the main grid
- [ ] Page is read-only (no edit/add/delete buttons)
