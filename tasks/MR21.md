# MR21: Manga Detail Chapter List

## Title
Show a manga detail page with chapters.

## Description
Create the manga detail page that organizes chapters into a clear list so readers can choose what to open next.

## Requirement
- Display a manga detail page for a selected title
- List available chapters under the manga
- Group or label chapters in a readable order
- Make chapter selection straightforward for readers

## Acceptance Criteria
- [ ] Readers can open a manga detail page
- [ ] The page shows the manga metadata and chapter list
- [ ] Chapters are presented in a clear and stable order
- [ ] A reader can select a chapter from the list

## Estimate Point
5
