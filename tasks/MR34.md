# MR34: Support Reading CBZ Files

## Title

Enable reading CBZ (Comic Book Zip) files.

## Description

Allow the application to load and read manga content from `.cbz` files, extracting images and presenting them in the reader UI.

## Requirement

- Detect and accept `.cbz` files
- Extract images in correct order
- Reuse existing manga reader UI if possible
- Handle invalid or corrupted CBZ files gracefully

## Acceptance Criteria

- [ ] User can open a CBZ file
- [ ] Images are displayed in correct reading order
- [ ] Unsupported or broken files show a clear error message
- [ ] Reading experience matches folder-based manga reading

## Estimate Point

5
