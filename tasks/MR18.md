# MR18: Chapter Path Validation and Security

## Title
Validate chapter paths and prevent traversal attacks.

## Description
Protect local chapter ingestion by validating paths before scan or save so only safe library locations are accepted.

## Requirement
- Reject directory traversal attempts using `..`
- Normalize incoming paths before use
- Reject paths that fall outside the allowed library root
- Return clear validation failures for invalid paths

## Acceptance Criteria
- [ ] Path traversal inputs are rejected
- [ ] Normalized paths are validated consistently on the backend
- [ ] Invalid paths do not reach the scan or save step
- [ ] Tests cover traversal, invalid, and valid path cases
