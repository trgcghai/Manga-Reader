# MR58: Frontend — Replace URL Text Input with CBZ File Upload in All Translation Dialogs

## Title

Replace the `url` text input in AddChapterDialog, AddTranslationDialog, and EditTranslationDialog with a CBZ file upload (matching the manga coverPath flow).

## Description

Currently the three translation dialogs have a text input for `url` (previously `folderPath`) where users type a path directly. This should be replaced with a file input for CBZ files, matching the same pattern as the manga cover upload in `MangaForm`.

The flow for each dialog changes from:
```
fill url text → submit(url)
```
to:
```
select cbz file → upload file → get url from response → submit(url)
```

### Key insights

- **AddChapterDialog** / **AddTranslationDialog**: Both call `useCreateChapterForManga(mangaId)`. The AddChapterDialog creates a chapter + its first translation together. The AddTranslationDialog reuses the same endpoint to add a translation to an existing chapter. For AddChapterDialog, `chapterId` is unknown until the chapter is created, so the file must be uploaded after chapter creation (3-step: create chapter → upload file → update translation URL). For AddTranslationDialog, `chapterId` is known from props, so file can be uploaded before the create call (2-step: upload file → create translation with URL).

- **EditTranslationDialog**: Calls `useUpdateTranslation(mangaId, chapterId)`. If the user selects a new file, upload it first, then update translation with the new URL. The old file cleanup is handled separately by MR59 (backend).

### Changes needed

1. **Add a new hook** — Add `useTranslationFileUpload(mangaId: number, chapterNumber: number)` to `frontend/src/hooks/useFile.ts` that calls `POST /files/upload/translation` with `mangaId`, `chapterNumber`, and the file. Wraps it with `useMutation`. (This requires MR57 to be implemented first.)

2. **AddChapterDialog** — Replace the `url` form field (`<form.Field name="url">`) with a file input. On submit: upload the file first (using `mangaId` + the `number` field value as `chapterNumber`), get the returned URL, then call `createChapter` with the URL.

3. **AddTranslationDialog** — Replace `url` text input with file input. On submit: upload file first (using `mangaId` + `chapterNumber` from props), get URL, then call `createChapter` with the URL.

4. **EditTranslationDialog** — Replace `url` text input with file input. Pre-fill with existing URL if no new file selected. On submit: if a new file is selected, upload it first (using `mangaId` + `chapterNumber` from props), get URL, then call `updateTranslation` with the new URL. If no new file, submit the existing URL unchanged.

## Requirement

- Add `useTranslationFileUpload(mangaId, chapterNumber)` hook to `frontend/src/hooks/useFile.ts`
  - Calls `POST /files/upload/translation` with `mangaId`, `chapterNumber`, `file`
  - Returns `UploadFileResponse` (same `{ key, url }` shape)
- AddChapterDialog: Replace text `url` input with CBZ file input. On submit, upload file then create chapter with returned URL.
- AddTranslationDialog: Same replacement. On submit, upload file then create translation.
- EditTranslationDialog: Replace text `url` input with CBZ file input. On submit, if file changed, upload then update translation. If unchanged, submit existing URL.
- Remove the `url` (or `folderPath`) field from the Zod schema in all three dialogs — validation moves to file type check.
- Show a file preview or filename after selection (matching MangaForm cover pattern).
