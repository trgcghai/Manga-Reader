# MR66: Frontend — CBZ Parsing and Basic Page Rendering

## Title

Install JSZip, create utility to download CBZ files and extract page images as object URLs, and implement the core page viewer with page mode (single/double display) and page-turn controls.

## Description

The CBZ file (a renamed ZIP containing page images) needs to be downloaded and extracted client-side. Each image is rendered as a page in the reader. This task covers the extraction pipeline and the page-mode viewer.

### Existing context

- `frontend/src/services/api/fileApi.ts` exports `downloadFile(url: string): Promise<Blob>` — uses `GET /files/download?url=...` with `responseType: 'blob'`
- `frontend/src/hooks/useFile.ts` exports `useFileDownload(): UseMutationResult<Blob, Error, string>` — wraps `downloadFile` as a `useMutation` hook, provides `mutateAsync(url)` for imperative download
- `frontend/src/types/translation.ts` defines `TranslationDetailResponse` with `url: string` (the CBZ download URL), plus `chapter.manga.id` and `chapter.manga.title`
- `frontend/src/stores/rootStore.ts` exports `useReaderStore` (zustand) with `setTotalPages(n: number)`, `currentPage: number`, `totalPages: number`, `readingMode: 'page' | 'scroll'`, `displayMode: 'single' | 'double'`
- `frontend/src/routes/_reader/reader.$translationId.tsx` is the reader page route, already loads translation via `useTranslation(Number(translationId))`
- Import alias `#/` maps to `frontend/src/`
- The route file uses path alias patterns: `import { useTranslation } from '#/hooks/useManga'`

### Changes needed

1. **Install JSZip** — `npm install jszip` in `frontend/`

2. **Create CBZ utility** — `frontend/src/utils/cbzParser.ts`:
   - `parseCbzPages(buffer: ArrayBuffer): Promise<Blob[]>`
     - Load via `new JSZip().loadAsync(buffer)`
     - Filter entries: only files with extensions `.jpg`, `.jpeg`, `.png`, `.webp` (case-insensitive)
     - Sort entries by filename using `Intl.Collator(undefined, { numeric: true, sensitivity: 'base' })` for natural sort order
     - Return each as a `Blob` with MIME type derived from extension (e.g., `image/jpeg`, `image/png`, `image/webp`)
     - Handle empty CBZ or no images found: throw `new Error('No valid page images found in CBZ file')`
   - `loadCbzAsObjectUrls(blobs: Blob[]): string[]`
     - Map `blobs` to `URL.createObjectURL(blob)`
   - `revokeObjectUrls(urls: string[]): void`
     - `urls.forEach(url => URL.revokeObjectURL(url))`
   - Export all three functions (no `downloadCbz` — the download is handled by `useFileDownload` in the hook)

3. **Create reader hook** — `frontend/src/hooks/useReaderPages.ts`:
   - Signature: `export function useReaderPages(url: string | undefined): { pages: string[], isLoading: boolean, error: string | null }`
   - Internal implementation:
     - Calls `useFileDownload()` (from `#/hooks/useFile`) to get `{ mutateAsync: (url: string) => Promise<Blob>, isPending, reset }`
     - Uses a `useRef<string[]>` to track current object URLs for cleanup
     - Primary `useEffect` that runs when `url` changes:
       - Guards: if `!url`, set pages to `[]`, loading to `false`, and return early
       - Sets `isLoading(true)`, `error(null)`, calls `reset()` on the mutation
       - Calls `mutateAsync(url)` to download the Blob, then converts to ArrayBuffer via `blob.arrayBuffer()`
       - Calls `parseCbzPages(arrayBuffer)` then `loadCbzAsObjectUrls(blobs)`
       - On success: calls `useReaderStore.getState().setTotalPages(blobs.length)`, updates `pages` state, sets `isLoading(false)`
       - On error: sets `error` to `error instanceof Error ? error.message : 'Failed to load CBZ'`, sets `isLoading(false)`
     - Cleanup effect: revokes all object URLs in the ref on unmount or when `url` changes
   - Use `useState` for `pages`, `isLoading`, `error`

4. **Create page viewer component** — `frontend/src/components/reader/PageViewer.tsx`:
   - Props interface:
     ```ts
     interface PageViewerProps {
       pages: string[]
       displayMode: 'single' | 'double'
       currentPage: number
       onNextPage: () => void
       onPrevPage: () => void
     }
     ```
   - In single mode:
     - Render one `<img>` tag with `src={pages[currentPage]}`
     - Centered with `<div className="flex items-center justify-center h-full">`
     - Image constrained with `className="max-h-screen max-w-full object-contain"`
     - Image `alt` attribute: `Page ${currentPage + 1}`
   - In double mode:
     - Render two `<img>` tags side by side
     - If `currentPage` is the last page and odd, show only one image centered
     - Left image: `pages[currentPage]`, right image (if exists): `pages[currentPage + 1]`
     - Container: `<div className="flex items-center justify-center gap-1 h-full">`
     - Each image: `className="max-h-screen max-w-[50vw] object-contain"`
     - `alt` attributes: `Page ${currentPage + 1}` and `Page ${currentPage + 2}`
   - Handle image load errors: `onError` sets `img.style.display = 'none'` and logs a warning
   - Handle `pages.length === 0` by rendering nothing
   - Handle `currentPage` out of bounds by clamping with `Math.min(currentPage, pages.length - 1)`

5. **Integrate into reader page** (`frontend/src/routes/_reader/reader.$translationId.tsx`):
   - Add imports:
     - `import { useReaderStore } from '#/stores/rootStore'`
     - `import { useReaderPages } from '#/hooks/useReaderPages'`
     - `import { PageViewer } from '#/components/reader/PageViewer'`
   - After fetching translation data with `useTranslation`, extract CBZ URL: `data?.url`
   - Call `useReaderPages(data?.url)` to get `{ pages, isLoading: pagesLoading, error: pagesError }`
   - Read from store: `const { currentPage, displayMode } = useReaderStore()`
   - Derive actions: `const nextPage = useReaderStore(s => s.nextPage)`, `const prevPage = useReaderStore(s => s.prevPage)`
   - Replace placeholder content div with:
     - If `pagesLoading`: render loading spinner (existing skeleton or a spinner)
     - If `pagesError`: render error display with retry
     - If `pages` is ready: render `<PageViewer pages={pages} displayMode={displayMode} currentPage={currentPage} onNextPage={nextPage} onPrevPage={prevPage} />`
   - Keep the translation header info (manga title, chapter number) as a small overlay at the top

6. **Cleanup** — Object URLs are revoked inside `useReaderPages` via the `revokeObjectUrls` utility on unmount or URL change
