# MR66: Frontend — CBZ Parsing and Basic Page Rendering

## Title

Install JSZip, create utility to download CBZ files and extract page images as object URLs, and implement the core page viewer with page mode (single/double display) and page-turn controls.

## Description

The CBZ file (a renamed ZIP containing page images) needs to be downloaded from Minio and extracted client-side. Each image is rendered as a page in the reader. This task covers the extraction pipeline and the page-mode viewer.

### Changes needed

1. **Install JSZip** — `npm install jszip`

2. **Create CBZ utility** — `frontend/src/utils/cbzParser.ts`:
   - `downloadCbz(url: string): Promise<ArrayBuffer>` — download via `GET /files/download?url=...`
   - `parseCbzPages(buffer: ArrayBuffer): Promise<Blob[]>` — use JSZip to extract image files sorted by name, return as Blobs
   - `loadCbzAsObjectUrls(blobs: Blob[]): string[]` — create object URLs from blobs (cleanup utility too)
   - Export helper functions

3. **Create reader hook** — `frontend/src/hooks/useReaderPages.ts`:
   - Accept `url: string` (the translation CBZ URL)
   - Downloads and parses the CBZ
   - Returns `{ pages: string[] (object URLs), isLoading, error }`
   - Updates `totalPages` in the reader store
   - Cleans up object URLs on unmount

4. **Create page viewer component** — `frontend/src/components/reader/PageViewer.tsx`:
   - Accepts `pages: string[]` (object URLs) and `displayMode`
   - **Single page mode**: Shows one image, centered, with max-width/max-height constraints
   - **Double page mode**: Shows two images side by side (spread), adapting to viewport width
   - Images scale to fit viewport while preserving aspect ratio
   - Handles portrait/landscape image orientations

5. **Integrate into reader page** — Wire `useReaderPages` and `PageViewer` into the reader route:
   - Fetch CBZ when translation loads
   - Pass object URLs to PageViewer
   - Show loading spinner while parsing
   - Center content vertically and horizontally

6. **Cleanup** — Revoke object URLs when component unmounts or pages change

## Requirement

- Install `jszip`

- Create `frontend/src/hooks/useReaderPages.ts` that uses the download API from MR62
