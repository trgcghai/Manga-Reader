# MR96: Create BatchImportDialog component with folder picker

## Title

Create `BatchImportDialog` component that uses `<input webkitdirectory>` for folder selection and `useBatchImport` for background execution.

## Description

The `BatchImportDialog` is a modal that allows importing multiple chapter files at once by selecting an entire folder. The dialog reuses existing UI patterns from `AddChapterDialog.tsx` for language and translator selection.

### UI Structure

1. **Folder picker**: A styled button that triggers `<input webkitdirectory>` (hidden). After selection, the file count is displayed (e.g., "15 files selected").
2. **File list preview**: A scrollable table showing:
   - Parsed chapter number (from filename)
   - Filename
   - Status indicator (pending / uploading / success / fail) — only visible while running
3. **Language selector**: Reuses `<Select>` with `useLanguageList` hook (same as `AddChapterDialog.tsx:166-200`).
4. **Translator selector**: Reuses `<TranslatorCombobox>` component.
5. **Submit / Cancel buttons**: Submit is disabled until a folder is selected, language and translator are chosen. Cancel closes the dialog.

### Behavior

- On submit, the dialog calls `useBatchImport.mutate(files, { languageId, translatorId })` and **immediately closes**.
- The toast from `useBatchImport` continues to update in the background.
- If the user reopens the dialog while import is running, a message is shown: "Import in progress... (12 / 15 files)" instead of the folder picker.
- Files are filtered by extension: only `.cbz` and `.zip` are included.

### Reuse existing components

- `#/components/ui/input` for the hidden `<input webkitdirectory>`
- `#/components/ui/dialog` for the modal shell
- `#/components/ui/select` for language picker
- `#/components/translator/TranslatorCombobox` for translator picker
- `#/components/ui/field` for field labels/errors
- `#/hooks/useLanguages` for language list
- `#/hooks/useBatchImport` from MR95
- `#/components/ui/button`
- `#/components/ui/scroll-area` (or a simple overflow-y div) for file list

### States

| State | Behavior |
|-------|----------|
| Initial (no folder) | Folder picker button shown, submit disabled |
| Folder selected | File count shown, submit enabled if lang + translator selected |
| Submitting | Dialog closes immediately, toast handles progress |
| Import in progress (re-open) | Non-interactive message with current progress |
| Import complete (re-open) | Shows "Last import: 12/15 succeeded" + reset button |

### Dependencies

- `@tanstack/react-form` is NOT needed for this dialog (vanilla React state for the simple form)
- The folder input must have `{ multiple: true, webkitdirectory: true }` attributes
