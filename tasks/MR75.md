# MR75: Add Reader Chapter List Endpoint

## Title

Add `GET /manga/reader/chapters` endpoint for chapter navigation selector.

## Description

Implement a new read-only API endpoint that returns a lightweight list of all chapters for a given manga. Each entry contains the best-matching `translationId` (using the same priority algorithm as MR74) plus first/last chapter flags. This enables the reader frontend to render a chapter jump/select UI with minimal data.

### Algorithm per chapter

For each chapter of the manga (ordered by `number` ASC), pick the best translation using the same priority as MR74:

1. **Same translator + same language** — match against the given `translatorId` and `language`
2. **Same language** — fallback to any translation with the same language
3. **No translation** — `translationId` is `null`

### Response shape

```json
[
  { "chapterId": 1, "title": "Chapter 1", "translationId": 10, "isFirstChapter": true, "isLatestChapter": false },
  { "chapterId": 2, "title": "Chapter 2", "translationId": 20, "isFirstChapter": false, "isLatestChapter": true },
  { "chapterId": 3, "title": null, "translationId": null, "isFirstChapter": false, "isLatestChapter": false }
]
```

No page data, CBZ URLs, availability flags, or fallback metadata.

### Changes needed

#### Backend

1. **Create `ReaderChapterItem` DTO** in `translation.dto.ts` (or a new `reader.dto.ts`):
   ```typescript
   export class ReaderChapterItem {
     chapterId: number;
     title: string | null;
     translationId: number | null;
     isFirstChapter: boolean;
     isLatestChapter: boolean;
   }
   ```

2. **Add repository method** to `ChapterRepository`:
   - `findAllByMangaId(mangaId: number): Promise<Chapter[]>` — returns all chapters for a manga ordered by `number` ASC, with `translations`, `translations.language`, `translations.translator` relations loaded.

3. **Create `ReaderService`** (or add to `ChapterService`) with method:
   ```typescript
   getChapterList(mangaId: number, translatorId: number, language: string): Promise<ReaderChapterItem[]>
   ```
   Logic:
   - Fetch all chapters via `chapterRepository.findAllByMangaId(mangaId)`
   - Iterate; on each chapter, apply the priority algorithm to find the best `translationId`
   - Set `isFirstChapter` for index 0, `isLatestChapter` for last index
   - Map to `ReaderChapterItem` response

4. **Add controller endpoint** in `MangaController`:
   ```typescript
   @Get('reader/chapters')
   getReaderChapters(
     @Query('mangaId', ParseIntPipe) mangaId: number,
     @Query('translatorId', ParseIntPipe) translatorId: number,
     @Query('language') language: string,
   ) {
     return this.readerService.getChapterList(mangaId, translatorId, language);
   }
   ```

5. **Register `ReaderService`** in `MangaModule` providers.

6. **Update tests**:
   - Add `ChapterRepository.findAllByMangaId` mock
   - Unit tests for `getChapterList` covering:
     - Exact match translationId resolved
     - Fallback match translationId resolved
     - No translation → `translationId: null`
     - `isFirstChapter` / `isLatestChapter` flags correct
     - Single chapter (both flags true)
     - Empty chapter list

#### Frontend

7. **Add `ReaderChapterItem` type** in `frontend/src/types/translation.ts`:
   ```typescript
   export interface ReaderChapterItem {
     chapterId: number;
     title: string | null;
     translationId: number | null;
     isFirstChapter: boolean;
     isLatestChapter: boolean;
   }
   ```

8. **Add API function** in `frontend/src/services/api/mangaApi.ts`:
   ```typescript
   export async function getReaderChapters(
     mangaId: number,
     translatorId: number,
     language: string,
   ): Promise<ReaderChapterItem[]> {
     const res = await axiosInstance.get<ReaderChapterItem[]>('/manga/reader/chapters', {
       params: { mangaId, translatorId, language },
     })
     return res.data
   }
   ```

## Requirement

- Create `GET /manga/reader/chapters` endpoint with query params `mangaId`, `translatorId`, `language`
- Each entry returns `chapterId`, `title`, `translationId` (best match per priority algorithm), `isFirstChapter`, `isLatestChapter`
- Priority: same translator+language → same language → `null`
- Chapters ordered by number ascending
