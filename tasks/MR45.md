# MR45: Public Library Search & Filter

## Title
Add search and filter controls to the public manga library page.

## Description
The library page (`/_app/index.tsx`) currently shows a paginated grid of all manga with no way to narrow results. Users need to search by title and filter by status/genre to find specific titles.

## Requirement
- Add a search input for title lookup
- Add filter dropdowns for status and genre
- Integrate with the existing backend query params (the manga list endpoint already supports `search`, `status`, `genreId`, `page`, `limit`)
- Maintain pagination integration — filtering resets to page 1
- Debounce search input (~300ms) to avoid excessive API calls
- Show active filter state (clearable chips/tags)

## Acceptance Criteria
- [ ] User can type a title search and see results update after a debounce
- [ ] User can filter by status (ongoing, completed, etc.)
- [ ] User can filter by genre
- [ ] Multiple filters can be combined
- [ ] Changing a filter resets pagination to page 1
- [ ] Active filters are visually indicated and individually dismissable
- [ ] Layout works on mobile (filters collapse or stack)

## Estimate Point
5
