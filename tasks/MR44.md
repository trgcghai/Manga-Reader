# MR44: Delete Translation

## Title

Allow deleting a translation from a chapter.

## Description

Users need to remove a translation entirely. This adds the backend endpoint, service logic, repository method, and frontend API/hook to support deletion.

---

## Backend Changes

### Repository

Add to `backend/src/modules/manga/translation.repository.ts`:

```typescript
delete = async (id: number): Promise<void> => {
  await this.repo.delete(id)
}
```

### Service

Add method to `backend/src/modules/manga/services/translation.service.ts` (same service created in MR43):

- `delete(translationId: number)`
  - Fetch translation by ID (throw `NotFoundException` if missing)
  - Call `TranslationRepository.delete(id)`

### Controller

Add to `backend/src/modules/manga/manga.controller.ts`:

```typescript
@Delete(':mangaId/translations/:id')
@HttpCode(HttpStatus.NO_CONTENT)
deleteTranslation(
  @Param('mangaId', ParseIntPipe) mangaId: number,
  @Param('id', ParseIntPipe) id: number,
) {
  return this.translationService.delete(id)
}
```

---

## Frontend Changes

### API Service

Add to `frontend/src/services/api/chapterApi.ts` (or `translationApi.ts`):

```typescript
export async function deleteTranslation(
  mangaId: number,
  translationId: number,
): Promise<void> {
  await axiosInstance.delete(`/mangas/${mangaId}/translations/${translationId}`)
}
```

### Hook

Add to `frontend/src/hooks/useTranslations.ts`:

- `useDeleteTranslation(mangaId: number)` — `useMutation` that calls `deleteTranslation`, invalidates `['mangas', 'detail', mangaId]` query key, shows toast on success/error

### UI (future)

- Delete button/icon on each translation row
- Confirmation dialog before deletion

---

## API

| Method | Path | Purpose |
|--------|------|---------|
| `DELETE` | `/mangas/:mangaId/translations/:id` | Delete a translation |

## Response

`204 No Content` on success.

## Acceptance Criteria

- [ ] Backend: `DELETE /mangas/:mangaId/translations/:id` deletes the translation
- [ ] Backend: returns 404 when translation not found
- [ ] Backend: returns 204 on successful deletion
- [ ] Frontend: `useDeleteTranslation` hook exists and invalidates manga detail cache
- [ ] All existing tests pass
