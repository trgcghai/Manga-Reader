# MR48: File Service

## Title

Create a file service that wraps Minio operations for manga image storage.

## Description

Build a `FileService` that provides a clean API for uploading, downloading, and deleting files to/from the Minio bucket. This service will be used by manga and chapter workflows to store cover images and page images.

## Requirement

- Create `backend/src/modules/file/services/file.service.ts`
- Implement methods: `upload(filename, buffer, mimetype)`, `download(filename)`, `delete(filename)`, `list(prefix?)`
- `upload` should return the public URL or object key
- `download` should return a readable stream
- Handle errors gracefully (file not found, connection failures)
- Support organizing files under prefixes (e.g., `covers/`, `pages/`, `thumbnails/`)

## Acceptance Criteria

- [ ] `FileService` is injectable with `MinioClient` dependency
- [ ] `upload` stores a file buffer to Minio and returns its key
- [ ] `download` retrieves a file as a readable stream
- [ ] `delete` removes a file from Minio
- [ ] `list` returns files under a given prefix
- [ ] Errors are wrapped in NestJS `HttpException` with appropriate status codes
- [ ] Service is registered in the file module
