# MR72: Replace custom drag-drop in MangaForm cover image upload

## Title

Refactor MangaForm cover image upload to use the shared `<FileDropzone>` component with image preview support.

## Description

`MangaForm` has a custom drag-and-drop implementation for cover image upload. It is the most complex of the five consumers: it includes image preview with a remove overlay button, MIME type validation (`['image/jpeg', 'image/png', 'image/webp', 'image/gif']`), and an `aspect-3/4` ratio container. The dropzone switches between a preview state (showing the image + Remove button) and an empty state (showing the drop zone).

Replace with the shared `<FileDropzone>` component (MR69) using `previewUrl` and `onRemove` props for the preview mode.

### Changes needed

- **Remove** the following local code:
  - `useState` for `dragOver`
  - `useRef` for `fileInputRef`
  - `handleDragOver`, `handleDragLeave`, `handleDrop`, `handleFileSelect` functions
  - The `role="button"` container div with its drag/keyboard handlers
  - The MIME type validation array and check
  - The image preview div + remove button overlay
  - The hidden `<input type="file">`
  - The `showCoverPreview` conditional rendering logic
  - Imports: remove `ChangeEvent`, `DragEvent`, `useRef` if no longer needed; remove `Upload`, `X`, `ImageIcon` from `lucide-react` if no longer used elsewhere
  - The `hasExistingCover` variable and `showCoverPreview` logic

- **Keep** (not part of the dropzone):
  - `coverPreview` state and `URL.revokeObjectURL` cleanup in `useEffect`
  - `coverRemoved` state (passed to parent via `onSubmit`)
  - `handleRemoveCover` function (wired to `onRemove` prop)

- **Add**:
  - Import `FileDropzone` from `#/components/ui/file-dropzone`
  - Replace the file upload section with:
    ```tsx
    <FileDropzone
      accept={{
        'image/jpeg': ['.jpg', '.jpeg'],
        'image/png': ['.png'],
        'image/webp': ['.webp'],
        'image/gif': ['.gif'],
      }}
      value={form.getFieldValue('coverFile')}
      onFileSelect={(file) => {
        form.setFieldValue('coverFile', file)
        if (file) {
          setCoverPreview(URL.createObjectURL(file))
          setCoverRemoved(false)
        }
      }}
      error={...} // field errors if any
      message="Drag & drop or click to upload"
      hint="JPG, PNG, WebP, GIF"
      previewUrl={showCoverPreview ? (coverPreview || form.getFieldValue('coverPath')) : undefined}
      onRemove={showCoverPreview ? handleRemoveCover : undefined}
      aspectRatio="aspect-3/4"
    />
    ```

### Verification

- MangaForm still accepts image files via drag-and-drop and click-to-browse
- Only `image/jpeg`, `image/png`, `image/webp`, `image/gif` are accepted
- Image preview shows when a file is selected (via `URL.createObjectURL`)
- Existing cover image shows preview when editing (via `coverPath`)
- Remove button appears over the preview and clears the selection
- Cover image area maintains `aspect-3/4` ratio
- Form submission with cover file works identically
