# MR79: Fix Page Counter for Double Mode

## Title

Show spread-aware page counter in double-page display mode.

## Description

The `PageIndicator` component in `PageViewer.tsx:11-16` always shows `{current + 1} / {total}` where `current` is the left-page index and `total` is the raw page count. In double mode this is misleading — a reader seeing "1 / 3" on a spread showing pages 1-2 expects spread-level numbering.

**File:** `frontend/src/components/reader/PageViewer.tsx:11-16`

### Current behavior (double mode, 5-page chapter):

| currentPage | Display | Meaning |
|-------------|---------|---------|
| 0 | "1 / 5" | Spread [1,2] |
| 2 | "3 / 5" | Spread [3,4] |
| 4 | "5 / 5" | Page [5] alone |

### Expected behavior (double mode, 5-page chapter):

| currentPage | Display (option A: range) | Display (option B: spread count) |
|-------------|--------------------------|----------------------------------|
| 0 | "1-2 / 5" | "Spread 1 / 3" |
| 2 | "3-4 / 5" | "Spread 2 / 3" |
| 4 | "5 / 5" | "Spread 3 / 3" |

## Requirement

- When `displayMode === 'double'`, the page counter shows the page range of the current spread (e.g., "1-2 / 5")
- When `displayMode === 'single'`, the counter stays as `{current + 1} / {total}`
- On the last odd page with no pair, show just that page number (e.g., "5 / 5")
- Single-mode behavior is unchanged

## Acceptance Criteria

- [ ] Double mode, 5 pages, spread [1,2]: counter shows "1-2 / 5"
- [ ] Double mode, 5 pages, spread [3,4]: counter shows "3-4 / 5"
- [ ] Double mode, 5 pages, last page alone: counter shows "5 / 5"
- [ ] Single mode, 3 pages, page 1: counter shows "2 / 3" (unchanged)
- [ ] `npm run build` passes with 0 errors
- [ ] `npm run test` passes with 0 failures (all existing + updated double-mode counter tests)
