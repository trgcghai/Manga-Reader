# MR36: Genre Management

## Title

Manage genres in admin panel.

## Description

Provide CRUD functionality for managing manga genres and associating them with mangas.

## Requirement

- Create, edit, delete genres
- List all available genres
- Allow assigning multiple genres to a manga
- Prevent duplicate genre names

## Acceptance Criteria

- [ ] Admin can create a new genre
- [ ] Admin can edit and delete a genre
- [ ] Manga can have multiple genres
- [ ] Duplicate genres are prevented

## Estimate Point

3
