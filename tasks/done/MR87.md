# MR87: Jump chapter frontend API and UI

## Title

Add frontend API layer and chapter jump select in ReaderSettingsSheet.

## Description

The reader settings sheet needs a chapter jump feature — a `<Select>` dropdown listing all chapters of the current manga. The user picks a chapter and the reader navigates to it. This depends on MR86 (backend endpoint).

### Changes needed

1. **Add `ReaderChapterItem` type** in `frontend/src/services/api/mangaApi.ts`:
   ```typescript
   export interface ReaderChapterItem {
     chapterId: number;
     title: string | null;
     translationId: number | null;
     isFirstChapter: boolean;
     isLatestChapter: boolean;
   }
   ```

2. **Add `getReaderChapters` API function** in the same file:
   ```typescript
   export async function getReaderChapters(
     mangaId: number,
     translatorId: number,
     language: string,
   ): Promise<ReaderChapterItem[]> {
     const res = await axiosInstance.get<ReaderChapterItem[]>('/manga/reader/chapters', {
       params: { mangaId, translatorId, language },
     })
     return res.data
   }
   ```

3. **Add `useReaderChapters` React Query hook** in `frontend/src/hooks/useManga.ts`:
   - Accepts `mangaId`, `translatorId`, `language`
   - Uses `getReaderChapters` as queryFn
   - Only enabled when all params are provided (`mangaId > 0`, `translatorId > 0`, `language` is set)

4. **Add chapter jump Select to ReaderSettingsSheet**:
   - Read `currentChapter` from store to get `mangaId`, `chapter id` (for default value)
   - Read `currentTranslation` to get `translatorId` and `language` from the loaded translation
   - If `currentChapter` is null (no chapter loaded), render nothing for this section
   - Use shadcn `Select` component:
     ```tsx
     <Select value={String(currentChapter.id)} onValueChange={handleJumpChapter}>
       <SelectTrigger>
         <SelectValue placeholder="Jump to chapter..." />
       </SelectTrigger>
       <SelectContent>
         {chapters.map((ch) => (
           <SelectItem key={ch.chapterId} value={String(ch.chapterId)} disabled={!ch.translationId}>
             {ch.title ?? `Chapter ${ch.chapterId}`}
           </SelectItem>
         ))}
       </SelectContent>
     </Select>
     ```
   - `handleJumpChapter` maps the selected chapterId to its `translationId` and navigates using `useNavigate`
   - Items with `translationId === null` are disabled (no translation available)

5. **Handle data dependencies**:
   - The settings sheet needs access to `mangaId`, `translatorId`, `language` — these come from the route's `data` prop, or from `currentTranslation` / `currentChapter` in the store
   - The route component currently passes `title` to `ReaderSettingsSheet`; extend to pass the needed params, or read from store directly

6. **Edge cases**:
   - Current chapter is disabled in the Select (user is already there)
   - Show a brief loading state while chapters fetch
   - On error, show nothing (silent failure — the jump feature is non-critical)
   - Navigating to current chapter is a no-op
   - Navigate via `useNavigate` to `/reader/$translationId`

## Requirement

- `ReaderSettingsSheet` shows a "Jump to Chapter" section with a Select dropdown
- Dropdown lists all chapters from the API, defaulting to current chapter
- Selecting a chapter navigates to its `translationId`
- Chapters without a translation are disabled in the list
- `cd frontend && npm run build` passes with 0 errors
