# MR64: Frontend — Install Zustand and Create Reader Store

## Title

Install zustand, create `stores/` directory, and implement `rootStore` with a `translationSlice` containing all reader-related state.

## Description

The reader needs global state that persists across component re-renders and route changes. Zustand provides a lightweight state management solution for this. A `stores/` directory will be created at `frontend/src/stores/` with a `rootStore.ts` that composes slices. The `translationSlice` holds all reader-related state.

### TranslationSlice fields

| Field | Type | Default | Description |
|---|---|---|---|
| `currentTranslation` | `TranslationDetail \| null` | `null` | Currently loaded translation |
| `currentChapter` | `{ id: number; number: number; title?: string; mangaId: number; mangaTitle: string } \| null` | `null` | Chapter and manga context for the current read |
| `currentPage` | `number` | `0` | Current page index being viewed (0-based) |
| `totalPages` | `number` | `0` | Total number of pages in current CBZ |
| `readingMode` | `'page' \| 'scroll'` | `'page'` | Page mode (turn pages) or scroll mode (continuous scroll) |
| `displayMode` | `'single' \| 'double'` | `'single'` | Single page or double-page spread |

### Actions

| Action | Description |
|---|---|
| `setCurrentTranslation(t)` | Set current translation + derive chapter/manga context |
| `setCurrentPage(n)` | Update current page index |
| `setTotalPages(n)` | Set total page count |
| `setReadingMode(mode)` | Switch between page and scroll mode |
| `setDisplayMode(mode)` | Switch between single and double page |
| `nextPage()` | Increment current page (clamped to totalPages - 1) |
| `prevPage()` | Decrement current page (clamped to 0) |
| `reset()` | Reset all state to defaults |

## Requirement

- Create `frontend/src/stores/` directory
- Install `zustand` (npm install zustand)
- Create `frontend/src/stores/rootStore.ts` with `create` + `translationSlice`
- Use `StateCreator` pattern for slice composition (future-proofing for more slices)
- Export `useReaderStore` hook from the store
- `cd frontend && npm run build` passes with 0 errors
