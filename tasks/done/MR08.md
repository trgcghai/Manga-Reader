# MR08: Chapter Image Discovery

## Title
Scan chapter folders and return ordered image files.

## Description
Create the service that reads a chapter image directory, filters valid image files, and returns them in natural order so the reader can display pages correctly.

## Requirement
- Accept a local chapter folder path
- Filter image files only (`jpg`, `jpeg`, `png`, `webp`, `gif`)
- Sort pages naturally (`001`, `002`, `010`)
- Support empty folder and missing path handling
- Provide test fixtures for chapter folder layouts

## Acceptance Criteria
- [ ] Image files are returned in natural sort order
- [ ] Non-image files are ignored
- [ ] Empty folders return an empty list
- [ ] Missing paths return a clear error
- [ ] Tests cover at least one valid fixture and one failure case

## Estimate Point
5
