# MR40: Manga Detail Admin Page

## Title
Admin manga detail page with info, chapter list, and translation list.

## Description
Build an admin page to view the full detail of a manga, including its metadata, a list of chapters, and each chapter's translations. This is the central management view for a single manga.

## Requirements

### Manga Info Section
- Display all manga metadata fields (title, alternative titles, status, authors, genres, cover, etc.)
- Show the data in a read-only card or section at the top of the page

### Chapter List Section
- List all chapters belonging to the manga in a table
- Each row shows: chapter title, release date, folder path, language, translator, note
- Columns for actions (edit, delete) — wire up but can be basic (edit opens a detail/edit view or dialog; delete shows confirmation)

### Translation List Section
- For each chapter, display its associated translations
- This can be shown as an expandable row in the chapter table, a nested table, or a separate tab/section
- Each translation row shows relevant fields

### Route & Navigation
- Route: `/admin/mangas/{mangaId}` (utilizing the existing path pattern)
- Link from the manga list table (clicking a manga row or an "edit/view" button navigates here)

### States
- **Loading**: Skeleton placeholders while fetching
- **Error**: Red error card if the manga or its data fails to load
- **Empty**: Graceful empty state if manga has no chapters yet
- **Data**: Full detail view with all sections populated

## Acceptance Criteria
- [ ] Navigating to `/admin/mangas/{id}` shows the manga detail page
- [ ] Manga info section correctly displays all metadata
- [ ] Chapter list shows all chapters with title, release date, language, translator
- [ ] Translations are visible per chapter (expandable or inline)
- [ ] Loading, error, and empty states render correctly
- [ ] Page is accessible from the manga list (via navigation/link)
- [ ] No regressions to existing manga list or other admin pages

## Notes
- Requires the backend to have endpoints for fetching manga detail with chapters and translations populated (verify or create if missing)
- Follow existing admin page patterns (see `/admin/authors`, `/admin/translators` for style reference)
- Follow Tailwind/shadcn UI patterns already established in the codebase
