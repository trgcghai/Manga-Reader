# MR71: Replace custom drag-drop in ImportDialog

## Title

Refactor ImportDialog to use the shared `<FileDropzone>` component for `.xlsx` file selection.

## Description

`ImportDialog` has its own drag-and-drop implementation for `.xlsx` file selection: manual `dragOver` state, `fileInputRef`, `handleDragOver`/`handleDragLeave`/`handleDrop`/`handleFileSelect` handlers, a hidden `<input type="file" accept=".xlsx">`, and a `role="button"` container div. It also includes client-side extension validation (`f.name.endsWith('.xlsx')`) and uses a `<FileSpreadsheet>` icon from `lucide-react`.

Replace with the shared `<FileDropzone>` component (MR69) configured for `.xlsx` with `selectedDisplay="icon"` to show the file icon and name.

### Changes needed

- **Remove** the following local code:
  - `useState` for `dragOver`
  - `useRef` for `fileInputRef`
  - `handleDragOver`, `handleDragLeave`, `handleDrop`, `handleFileSelect` functions
  - The `role="button"` container div with its drag/keyboard handlers
  - The hidden `<input type="file">`
  - The conditional file display (Upload icon vs. FileSpreadsheet icon vs. text)
  - Imports: remove `ChangeEvent`, `DragEvent`, `useRef` if no longer needed; remove `Upload`, `FileSpreadsheet` from `lucide-react` if no longer used elsewhere
  - The `.endsWith('.xlsx')` client validation (handled by the `accept` prop)

- **Add**:
  - Import `FileDropzone` from `#/components/ui/file-dropzone`
  - Replace the file upload section with:
    ```tsx
    <FileDropzone
      accept={{ 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet': ['.xlsx'] }}
      value={file}
      onFileSelect={(f) => setFile(f)}
      message="Drag and drop your .xlsx file here, or click to browse"
      hint=".xlsx"
      icon={<FileSpreadsheet className="size-8 text-green-600" />}
      selectedDisplay="icon"
    />
    ```

### Verification

- ImportDialog still opens, accepts drag-and-drop and click-to-browse for `.xlsx`
- Selected file shows with `<FileSpreadsheet>` icon and filename
- Non-.xlsx files are rejected (browser file dialog filters by accept)
- Import button is disabled until a file is selected
- Download template button still works
- Form submission works identically
