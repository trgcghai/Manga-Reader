# MR89: Zustand store persist middleware

## Title

Add persist middleware to Zustand reader store for cross-session state survival.

## Description

The Zustand reader store (`frontend/src/stores/rootStore.ts`) currently loses all state on page refresh — preferences (`readingMode`, `displayMode`), reading progress (`currentPage`, `totalPages`, `scrollPosition`), and the loaded translation data (`currentTranslation`, `currentChapter`) are all reset to defaults.

Add `zustand/middleware`'s `persist` to serialize all state fields to `localStorage` and rehydrate on load. The app runs inside TanStack Start (SSR), so the persistence layer must gracefully handle environments where `localStorage` is unavailable (server-side render, or if the storage API throws). Use a custom storage adapter that catches errors and falls back to in-memory.

### What to persist

All state fields:
- `readingMode` — user preference
- `displayMode` — user preference
- `currentPage` — reading progress
- `totalPages` — needed alongside currentPage for display consistency
- `scrollPosition` — vertical scroll offset in scroll mode
- `currentTranslation` — the loaded translation API response (allows restoring full reader state)
- `currentChapter` — derived from translation but persisted for quick access

### Implementation details

- Use `persist` from `zustand/middleware` (bundled with zustand 5.x — no install needed)
- Storage key: `manga-reader-store`
- `partialize` option to whitelist only state fields, excluding action functions
- Custom `storage` object that wraps `localStorage` with try/catch for SSR safety
- `version` field set to `1` for future schema migrations
- Apply at the `create()` call level, not inside the slice

### Changes needed

1. Import `persist` from `zustand/middleware` in `rootStore.ts`
2. Create SSR-safe storage adapter wrapping `localStorage` with try/catch
3. Wrap `create<TranslationSlice>()(translationSlice)` with `persist(...)`
4. Add `partialize` to persist only state fields (skip action functions)
5. Set `name: 'manga-reader-store'`, `version: 1`
6. Import `StateCreator` type with persist middleware for correct typing
7. Verify build passes (`cd frontend && npm run build`)

## Requirement

- Store state survives full page reload
- All state fields are restored on rehydrate
- No errors or warnings in SSR/server context
- `cd frontend && npm run build` passes with 0 errors
