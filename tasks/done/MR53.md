# MR53: Frontend — Rename folderPath to url in API Types and Components

## Title

Update all frontend TypeScript and TSX files to use `url` instead of `folderPath` for the Translation field.

## Description

After the backend renames `folderPath` to `url` in DTOs and API responses, the frontend must match. This includes the API type definitions, dialog components that submit the field, and display components that render it.

## Requirement

- Update `mangaApi.ts`:
  - Rename `folderPath` to `url` in `TranslationDetail` interface
  - Rename `folderPath` to `url` in `CreateChapterPayload` interface
  - Rename `folderPath` to `url` in `UpdateTranslationPayload` interface
- Update `AddChapterDialog.tsx`: change `folderPath` field name in the form schema and submission
- Update `AddTranslationDialog.tsx`: change `folderPath` field name in form schema and submission
- Update `EditTranslationDialog.tsx`: change `folderPath` field name in form schema and submission
- Update `$id.index.tsx`: change `{tr.folderPath}` to `{tr.url}` in the JSX

## Acceptance Criteria

- [ ] All frontend API interfaces use `url` instead of `folderPath`
- [ ] All dialog form schemas use `url` instead of `folderPath`
- [ ] Display component shows the renamed field
- [ ] Frontend builds without TypeScript errors (`cd frontend && npm run build`)
- [ ] Frontend lint passes (`cd frontend && npm run lint`)

2
