# MR05: Redis Setup & Cache Manager Configuration

## Description
Set up Redis connection in the NestJS backend using `@nestjs/cache-manager` and `cache-manager-redis-store`, configure caching, and verify connectivity with the Docker Compose Redis service.

## Requirements
- Install `@nestjs/cache-manager`, `cache-manager`, `cache-manager-redis-store`
- Configure `CacheModule.register()` with environment variables:
  - `REDIS_URL` (e.g., `redis://redis:6379`)
- Set up cache TTL defaults
- Create a `CacheModule` or integrate into `AppModule`
- Add Redis health check
- Works with Docker Compose `redis` service (port 6379)

## Acceptance Criteria
- [ ] Backend connects to Redis on startup
- [ ] Connection uses `REDIS_URL` environment variable
- [ ] `CacheModule` is properly registered in `AppModule`
- [ ] Health check endpoint verifies Redis connectivity (`PING` → `PONG`)
- [ ] Cache set/get operations work in test endpoint
- [ ] Works with `docker compose up redis`
- [ ] Redis persistence (`--appendonly yes`) is configured in compose
