# MR09: Basic Manga REST API

## Title
Expose manga list and detail endpoints.

## Description
Implement the first backend API endpoints needed by the frontend so it can list manga and open a manga detail page.

## Requirement
- Add `GET /manga`
- Add `GET /manga/:id`
- Return manga with basic metadata and relationships needed by the frontend
- Use the entity/model layer created in Sprint 1
- Return proper 404 responses for missing manga

## Acceptance Criteria
- [ ] `GET /manga` returns a list of manga
- [ ] `GET /manga/:id` returns manga detail data
- [ ] Missing manga returns 404
- [ ] Responses are stable enough for frontend consumption
- [ ] API tests cover success and not-found paths

3
