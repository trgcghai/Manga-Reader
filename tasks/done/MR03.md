# MR03: PostgreSQL Setup & TypeORM Configuration

## Description
Set up PostgreSQL connection in the NestJS backend using TypeORM, configure the connection module, and verify connectivity with the Docker Compose Postgres service.

## Requirements
- Install `@nestjs/typeorm`, `typeorm`, `pg`
- Configure `TypeOrmModule.forRoot()` with environment variables:
  - `DATABASE_URL` or individual `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`
- Create a `DatabaseModule` or integrate into `AppModule`
- Add connection health check
- Configure entity loading path (`src/**/*.entity.ts`)
- Enable auto-migrations or manual migration setup
- Works with Docker Compose `postgres` service (port 5432)

## Acceptance Criteria
- [ ] Backend connects to PostgreSQL on startup
- [ ] Connection uses environment variables (no hardcoded credentials)
- [ ] `TypeOrmModule` is properly registered in `AppModule`
- [ ] Health check endpoint verifies DB connectivity
- [ ] Migration script runs successfully (`npm run typeorm migration:run`)
- [ ] Works with `docker compose up postgres`
- [ ] Connection pool configuration is documented
