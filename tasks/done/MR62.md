# MR62: Frontend — Add downloadFile API Function and useFileDownload Hook

## Title

Add `downloadFile` function to `fileApi.ts` and `useFileDownload` hook to `useFile.ts` for downloading files from the backend download endpoint.

## Description

The frontend needs to be able to download files (e.g., CBZ chapters) from Minio through the backend. A `downloadFile` function in the API layer calls `GET /files/download?url=<url>` and returns the response as a `Blob`. A `useFileDownload` hook in `useFile.ts` wraps this with loading/error state management.

### Changes needed

1. **fileApi.ts** — Add `downloadFile(url: string): Promise<Blob>`:
   - Use `axiosInstance.get` with `responseType: 'blob'` and `params: { url }`
   - Return `res.data` (the Blob)

2. **useFile.ts** — Add `useFileDownload()` hook:
   - Use `useMutation` from `@tanstack/react-query`
   - Accept `url: string` as mutation input
   - Return the Blob from `downloadFile(url)`

## Requirement

- Add `downloadFile(url: string): Promise<Blob>` to `frontend/src/services/api/fileApi.ts`
  - `axiosInstance.get('/files/download', { params: { url }, responseType: 'blob' })`
- Add `useFileDownload()` hook to `frontend/src/hooks/useFile.ts`
  - Returns `useMutation<Blob, Error, string>` where mutationFn calls `downloadFile`
- `cd frontend && npm run build` passes with 0 errors

## Acceptance Criteria

- [ ] `downloadFile(url)` calls `GET /files/download?url=<url>` and returns a Blob
- [ ] `useFileDownload()` returns a mutation with `mutate`, `isPending`, `error`, `data` (Blob)
- [ ] Existing tests still pass
- [ ] `cd frontend && npm run build` passes with 0 errors
