# MR69: Install react-dropzone and create shared FileDropzone component

## Title

Install `react-dropzone` dependency and create a reusable `<FileDropzone>` component that unifies the drag-and-drop file upload UX across all forms.

## Description

Currently, every dialog/form that accepts a file upload duplicates drag-and-drop logic: `dragOver` state, `fileInputRef`, `handleDragOver`/`handleDragLeave`/`handleDrop` handlers, a hidden `<input type="file">`, and a `role="button"` div. This leads to:

- Inconsistencies in styling, behavior, and accessibility
- Manual MIME/extension validation repeated in each component
- Poor keyboard accessibility (Enter/Space handlers are copy-pasted)
- No consistent drag-over visual feedback

`react-dropzone` provides a battle-tested hook (`useDropzone`) that handles drag events, file open dialogs, keyboard activation, and accessibility attributes. A shared `<FileDropzone>` component wraps it with a consistent UI and configurable options.

### Existing drag-drop implementations to be unified

| Component | Accept | Current approach | Unique features |
|---|---|---|---|
| `AddChapterDialog` | `.cbz,application/zip` | Custom `dragOver` state + hidden input + `role="button"` | Shows `<Badge>` with filename on select |
| `AddTranslationDialog` | `.cbz,application/zip` | Same pattern as AddChapterDialog | Shows `<Badge>` with filename on select |
| `EditTranslationDialog` | `.cbz,application/zip` | Same pattern | Shows `<Badge>` + "Current file" badge |
| `ImportDialog` | `.xlsx` | Same pattern but with `endsWith` check | Shows `<FileSpreadsheet>` icon, different text |
| `MangaForm` | image/* | Same pattern with MIME array check | Image preview, remove button, `aspect-3/4` |

### Changes needed

1. **Install `react-dropzone`** — `cd frontend && npm install react-dropzone`

2. **Create `frontend/src/components/ui/file-dropzone.tsx`**:
   - Accepts these props (matching all 5 consumer needs):
     ```ts
      interface FileDropzoneProps {
        accept: Record<string, string[]>  // useDropzone native format, e.g. { 'application/zip': ['.cbz', '.zip'] }
        onFileSelect: (file: File | null) => void
        value: File | null
        error?: string
        disabled?: boolean
        className?: string
        icon?: ReactNode         // defaults to <Upload className="size-8 text-muted-foreground" />
        message?: string         // defaults to "Drag and drop your file here, or click to browse"
        hint?: string            // shown below message, e.g. "CBZ, ZIP"
        selectedDisplay?: 'badge' | 'icon' | 'none'  // how to show selected file
        previewUrl?: string      // when set, shows image preview instead of drop zone
        onRemove?: () => void    // shown when previewUrl is set
        aspectRatio?: string     // for cover image, e.g. "aspect-3/4"
      }
     ```
   - Uses `useDropzone` internally:
     - `onDrop` calls `onFileSelect` with the first accepted file
     - `getRootProps()` spread onto the container div
     - `getInputProps()` for the hidden input
     - `isDragActive` for visual feedback
   - Container style: dashed border, rounded-lg, focus-visible ring, cursor-pointer
   - States:
     - **Empty**: icon + message + hint + "Browse" button
     - **Selected (badge mode)**: shows `<Badge>` with filename
     - **Selected (icon mode)**: shows icon + filename
     - **Preview mode**: renders `<img>` with the preview URL + remove overlay button
   - Drag-over state: `isDragActive ? 'border-primary bg-primary/5' : 'border-muted-foreground/25 hover:border-muted-foreground/50'`
   - Error state: red border or passes through `error` string

3. **Create `frontend/src/__tests__/file-dropzone.spec.tsx`**:
   - Renders empty state with message
   - Renders selected file badge when value is set
   - Calls onFileSelect when file is dropped (simulate drop via fireEvent.drop on root)
   - Calls onFileSelect when file is selected via input change
   - Shows drag-active styling (via isDragActive — may need to mock partial useDropzone)
   - Renders image preview when previewUrl is provided
   - Calls onRemove when remove button is clicked
   - Shows error message when error prop is set
