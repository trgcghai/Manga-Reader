# MR14: Language Seeding and List-Only API

## Title
Auto-seed languages on startup, restrict language API to read-only.

## Description
On application startup, check if the Language table is empty. If empty, seed it with a hardcoded comprehensive list of world languages. Remove all write endpoints (create, update, delete) for Language — only keep the list endpoint (findAll, no pagination, return all records).

## Requirement
- Seed file runs on app startup (via OnApplicationBootstrap or similar lifecycle hook)
- If Language table is empty, insert a hardcoded list of world languages (id, code, name)
- Remove POST /language (create)
- Remove PATCH /language/:id (update)
- Remove DELETE /language/:id (delete)
- Keep GET /language (list all, no pagination)
- Language entity fields remain: id, code (unique), name, timestamps

## Acceptance Criteria
- [ ] Languages are auto-seeded into the database on first startup
- [ ] Subsequent startups do NOT duplicate seed data
- [ ] GET /language returns all languages (no pagination)
- [ ] POST /language returns 404 or is removed
- [ ] PATCH /language/:id returns 404 or is removed
- [ ] DELETE /language/:id returns 404 or is removed
