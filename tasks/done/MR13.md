# MR13: Translator CRUD

## Title
Standalone translator CRUD management.

## Description
Full CRUD for translators. A translator is a standalone entity with no relation to manga, chapters, or any other module.

## Requirement
- Allow creating a translator with name and optional note
- Allow listing all translators (searchterm, pagination)
- Allow viewing a single translator by id
- Allow updating a translator's name and note
- Allow deleting a translator
- Prevent duplicate translator names

## Acceptance Criteria
- [ ] Admin can create a translator from the UI
- [ ] Admin can list all translators
- [ ] Admin can view a single translator
- [ ] Admin can update a translator
- [ ] Admin can delete a translator
- [ ] Translator changes persist through the API and reload correctly

## Estimate Point
3
