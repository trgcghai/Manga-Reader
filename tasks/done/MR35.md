# MR35: Author Management

## Title

Manage authors in admin panel.

## Description

Provide CRUD functionality for managing authors and linking them to mangas.

## Requirement

- Create, edit, delete authors
- List authors with basic information
- Allow assigning authors to mangas
- Prevent duplicate author names

## Acceptance Criteria

- [ ] Admin can create a new author
- [ ] Admin can edit and delete an author
- [ ] Manga can be associated with one or more authors
- [ ] Duplicate authors are not allowed

## Estimate Point

3
