# MR50: File Upload for Create Manga Flow

## Title

Replace the text-based cover path input with a file picker that uploads to Minio on form submit.

## Description

The `MangaForm.tsx` currently has a `coverPath` text field where users manually type a path like `/covers/one_piece.jpg`. After MR49, the backend has `POST /files/upload` that accepts multipart file uploads and returns a Minio URL. Change the flow so users select a file, then on submit:
1. Upload the file via `POST /files/upload`
2. Get the Minio URL from the response
3. Submit the manga creation with that URL as `coverPath`

This is a frontend-only task — the backend endpoints exist.

## Requirement

- Replace the `coverPath` text `<Input>` in `MangaForm.tsx` with a file `<Input type="file">` that accepts images (jpg, png, webp, gif)
- Create an upload API function `uploadFile(file: File)` in `frontend/src/services/api/fileApi.ts` that POSTs multipart to `/files/upload` and returns `{ key, url }`
- Note: the default axios instance uses `Content-Type: application/json` — the upload request must use `Content-Type: multipart/form-data` (set per-request, not globally)
- In `new.tsx`, modify the `onSubmit` handler to:
  a. If a file was selected, call `uploadFile` first to get the URL
  b. Set the URL as `coverPath` in the `CreateMangaPayload`
  c. Submit to `useCreateManga`
- Show upload progress/loading state while the file is uploading
- Handle upload errors — show the error message instead of submitting with a broken URL

## Acceptance Criteria

- [ ] `coverPath` field is a file input, not a text path input
- [ ] Only image files (jpg, png, webp, gif) can be selected
- [ ] On submit, the file is uploaded first, then manga is created with the returned URL
- [ ] Loading state shows during upload
- [ ] Upload errors are displayed to the user
- [ ] Existing form fields (title, status, etc.) still work as before
- [ ] The edit manga page (`$id.edit.tsx`) still works — it uses the same MangaForm but may not need the upload flow (optional: keep text input for edit, or always use upload)
