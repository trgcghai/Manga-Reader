# MR06: Define Core Entities

## Title
Define core domain entities for manga library data.

## Description
Create the core data model for the manga reader domain so the app can store and relate manga, chapters, translations, and translators consistently across PostgreSQL and MongoDB-backed features.

## Requirement
- Define `Manga`, `Chapter`, `Translation`, and `Translator` entities/schemas
- Map relational fields to PostgreSQL via TypeORM
- Keep translation metadata ready for language and translator selection
- Include fields from `overview.md` such as title, description, cover path, chapter number, release date, notes, language, translator, and folder path

## Acceptance Criteria
- [ ] Entity/schema definitions exist for all 4 domain objects
- [ ] Relations between manga, chapters, translations, and translators are modeled
- [ ] Entities include the fields required by `overview.md`
- [ ] Database migration or schema sync can be generated successfully
- [ ] Unit tests cover entity shape or mapping rules
