# MR88: Jump to page select in ReaderSettingsSheet

## Title

Add page jump Select in ReaderSettingsSheet for page mode navigation.

## Description

The reader settings sheet currently has display mode, reading mode, and navigation shortcut sections. Add a "Jump to Page" section that lets the user quickly navigate to a specific page when in **page mode**. This is hidden when `readingMode === 'scroll'`.

### Page options by displayMode

- **Single mode**: each page is its own item — "1", "2", "3", "4", "5"
- **Double mode**: pages are grouped into spreads — "1-2", "3-4", "5" (last lone page shown by itself if odd page count)

### Navigation behavior

| Option | Action |
|--------|--------|
| Selecting "1-2" in double mode | `setCurrentPage(0)` — lands on the spread starting at page 1 |
| Selecting "3-4" in double mode | `setCurrentPage(2)` — lands on the spread starting at page 3 |
| Selecting "5" in double mode | `setCurrentPage(4)` — lone last page |
| Selecting "3" in single mode | `setCurrentPage(2)` — lands on page 3 |

The key detail: in double mode, both pages in a pair share the same spread, so choosing the pair always navigates to the even index (start of the spread). The Select value corresponds to the page index, not the display label.

### Implementation

1. **Props update**: `ReaderSettingsSheet` needs access to `totalPages`, `currentPage`, and `setCurrentPage`. These are already in the Zustand store — read them directly inside the component:
   ```tsx
   const currentPage = useReaderStore((s) => s.currentPage)
   const totalPages = useReaderStore((s) => s.totalPages)
   const setCurrentPage = useReaderStore((s) => s.setCurrentPage)
   ```

2. **Compute page items** based on `displayMode`:
   ```typescript
   function getPageItems(displayMode: 'single' | 'double', totalPages: number) {
     if (displayMode === 'single') {
       return Array.from({ length: totalPages }, (_, i) => ({
         value: String(i),
         label: String(i + 1),
       }))
     }
     // double mode: group into spreads
     const items: { value: string; label: string }[] = []
     for (let i = 0; i < totalPages; i += 2) {
       const end = Math.min(i + 2, totalPages)
       items.push({
         value: String(i),
         label: end - i === 2 ? `${i + 1}-${end}` : String(i + 1),
       })
     }
     return items
   }
   ```

3. **Render the section** only when `readingMode === 'page'`:
   ```tsx
   {readingMode === 'page' && (
     <>
       <Separator />
       <div className="flex flex-col gap-3">
         <h3 className="text-xs font-medium text-muted-foreground uppercase tracking-wider">
           Jump to Page
         </h3>
         <Select value={String(currentPage)} onValueChange={(v) => setCurrentPage(Number(v))}>
           <SelectTrigger>
             <SelectValue />
           </SelectTrigger>
           <SelectContent>
             {pageItems.map((item) => (
               <SelectItem key={item.value} value={item.value}>
                 {item.label}
               </SelectItem>
             ))}
           </SelectContent>
         </Select>
       </div>
     </>
   )}
   ```

4. **Dependencies**: The existing shadcn `Select` component is already available at `frontend/src/components/ui/select.tsx` — no install needed.

5. **Edge cases**:
   - When `totalPages === 0` (no pages loaded), render nothing for this section
   - Changing `displayMode` while the sheet is open causes the items to recompute (React handles this via re-render)
   - Selecting the current page is a no-op (Select fires onValueChange even for the same value — harmless)

## Requirement

- "Jump to Page" section appears in ReaderSettingsSheet only when `readingMode === 'page'`
- In single mode: displays "1", "2", "3", ... as selectable items
- In double mode: displays "1-2", "3-4", "5", ... grouping pages into spreads
- Selecting an item navigates to the corresponding spread/page
- Section is hidden when `readingMode === 'scroll'`
- `cd frontend && npm run build` passes with 0 errors
