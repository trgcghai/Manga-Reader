# MR38: Import Excel to Bulk Create Manga

## Title

Import Excel file to bulk create manga entries.

## Description

Allow admins to upload an `.xlsx` file containing manga rows to create multiple manga entries at once. The backend parses the worksheet, validates each row, and bulk-creates manga with authors/genres. Results (success count, per-row errors) are returned and displayed in the UI.

## Requirement

- Backend: `POST /mangas/import` endpoint accepting a `.xlsx` file upload
- Parse worksheet rows into `CreateMangaPayload` (title, status, description, alternativeTitles, coverPath, authors, genres). Multi-value columns (authors, genres, alternativeTitles) are comma-separated. Backend uses a CSV-style parser so values containing commas can be double-quoted (`"Action, Adventure"`).
- For each row, create the manga reusing existing authors/genres by name via `AuthorService.findOrCreate` / `GenreService.findOrCreate`
- Return a result object: `{ total: number, created: number, errors: [{ row: number, message: string }] }`
- If a row fails, skip it and continue processing remaining rows (do not roll back successful rows)
- Frontend: import button on admin manga list page, file picker for `.xlsx`
- Frontend: display import result summary (success count, list of row errors)
- Frontend: add `useImportManga` hook + `importManga` API call

## Acceptance Criteria

- [ ] Backend accepts `.xlsx` upload at `POST /mangas/import`
- [ ] Each worksheet row is parsed, validated, and manga is created with authors/genres
- [ ] Errors are reported per row without aborting the entire import
- [ ] Frontend has an import button and file picker
- [ ] Frontend shows success count and per-row errors after import
- [ ] Backend unit tests cover parsing, validation, and error handling
- [ ] E2e test covers a successful import with multiple rows
