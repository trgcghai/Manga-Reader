# MR43: Edit Translation

## Title

Allow editing translation details (language, translator, folder path).

## Description

Users need to update a translation's language, translator, or folder path after creation. This adds the backend endpoint, service logic, repository method, and frontend API/hook to support this.

---

## Backend Changes

### DTO

Create `backend/src/modules/manga/dto/translation.dto.ts`:

```typescript
import { IsNumber, IsOptional, IsString, MinLength } from 'class-validator'

export class UpdateTranslationDto {
  @IsOptional()
  @IsNumber()
  languageId?: number

  @IsOptional()
  @IsNumber()
  translatorId?: number

  @IsOptional()
  @IsString()
  @MinLength(1)
  folderPath?: string
}
```

### Repository

Add to `backend/src/modules/manga/translation.repository.ts`:

```typescript
findById = async (id: number): Promise<Translation | null> => {
  return await this.repo.findOne({
    where: { id },
    relations: ['chapter', 'chapter.manga'],
  })
}

update = async (id: number, data: Partial<Translation>): Promise<Translation> => {
  await this.repo.update(id, data)
  return await this.repo.findOne({ where: { id } })
}
```

### Service

Create `backend/src/modules/manga/services/translation.service.ts`:

- `update(translationId: number, dto: UpdateTranslationDto)`
  - Fetch translation by ID (throw `NotFoundException` if missing)
  - If `languageId` provided: verify language exists via `LanguageService.findOne()`
  - If `translatorId` provided: verify translator exists via `TranslatorService.findOne()`
  - If language+translator changed: check for unique constraint conflict with `TranslationRepository.findByChapterAndLanguageAndTranslator()`, throw `ConflictException` if duplicate
  - Call `TranslationRepository.update(id, partial)`
  - Return updated translation

### Controller

Add to `backend/src/modules/manga/manga.controller.ts`:

```typescript
@Patch(':mangaId/translations/:id')
updateTranslation(
  @Param('mangaId', ParseIntPipe) mangaId: number,
  @Param('id', ParseIntPipe) id: number,
  @Body() dto: UpdateTranslationDto,
) {
  return this.translationService.update(id, dto)
}
```

### Module

Register `TranslationService` in `backend/src/modules/manga/manga.module.ts` providers and inject into `MangaController`.

## Frontend Changes

### API Service

Add to `frontend/src/services/api/chapterApi.ts` (or create `translationApi.ts` following pattern):

```typescript
export interface UpdateTranslationPayload {
  languageId?: number
  translatorId?: number
  folderPath?: string
}

export async function updateTranslation(
  mangaId: number,
  translationId: number,
  payload: UpdateTranslationPayload,
): Promise<void> {
  await axiosInstance.patch(`/mangas/${mangaId}/translations/${translationId}`, payload)
}
```

### Hook

Create `frontend/src/hooks/useTranslations.ts`:

- `useUpdateTranslation(mangaId: number)` — `useMutation` that calls `updateTranslation`, invalidates `['mangas', 'detail', mangaId]` query key, shows toast on success/error

### UI (future)

- Edit button on each translation row in the collapsible table
- Dialog or inline edit for language/translator/folderPath fields

## API

| Method | Path | Purpose |
|--------|------|---------|
| `PATCH` | `/mangas/:mangaId/translations/:id` | Update translation fields |

## Payload

```json
{
  "languageId": 2,
  "translatorId": 3,
  "folderPath": "/chapters/vol1/ch1-en-v2"
}
```

All fields are optional.

## Acceptance Criteria

- [ ] Backend: `PATCH /mangas/:mangaId/translations/:id` updates language, translator, or folderPath
- [ ] Backend: returns 404 when translation not found
- [ ] Backend: returns 409 when language+translator combination already exists for the chapter
- [ ] Frontend: `useUpdateTranslation` hook exists and invalidates manga detail cache
- [ ] All existing tests pass
