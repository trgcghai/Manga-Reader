# MR70: Replace custom drag-drop in AddChapterDialog, AddTranslationDialog, EditTranslationDialog

## Title

Refactor AddChapterDialog, AddTranslationDialog, and EditTranslationDialog to use the shared `<FileDropzone>` component for CBZ/ZIP file selection.

## Description

Three chapter/translation dialogs have identical drag-and-drop implementations for CBZ/ZIP file selection: manual `dragOver` state, `fileInputRef`, `handleDragOver`/`handleDragLeave`/`handleDrop`/`handleFileSelect` handlers, a hidden `<input type="file" accept=".cbz,application/zip">`, and a `role="button"` container div. Replace all of them with the shared `<FileDropzone>` component (MR69).

### Components to update

1. **`frontend/src/components/chapter/AddChapterDialog.tsx`**
2. **`frontend/src/components/chapter/AddTranslationDialog.tsx`**
3. **`frontend/src/components/chapter/EditTranslationDialog.tsx`**

### Changes needed per component

- **Remove** the following local code:
  - `useState` for `dragOver`
  - `useRef` for `fileInputRef`
  - `handleDragOver`, `handleDragLeave`, `handleDrop`, `handleFileSelect` functions
  - The `role="button"` container div with its drag/keyboard handlers
  - The hidden `<input type="file">`
  - The conditional file display (Badge vs. empty state with Upload icon)
  - Imports: remove `ChangeEvent`, `DragEvent`, `useRef`, `useState` if no longer needed (only `useState` may still be needed for other state in AddChapterDialog — check)
  - Remove `Upload` from `lucide-react` if no longer used elsewhere in the file

- **Add**:
  - Import `FileDropzone` from `#/components/ui/file-dropzone`
  - Replace the entire file upload div + hidden input with:
    ```tsx
    <FileDropzone
      accept={{ 'application/zip': ['.cbz', '.zip'] }}
      value={field.state.value}
      onFileSelect={(file) => field.handleChange(file!)}
      error={field.state.meta.errors[0]?.message}
      message="Drag and drop your CBZ file here, or click to browse"
      hint="CBZ, ZIP"
      selectedDisplay="badge"
    />
    ```
  - For `EditTranslationDialog`: additionally keep the "Current file" badge display below the `FileDropzone` (it is not part of the dropzone itself)

### Verification

- Each dialog still opens, accepts drag-and-drop and click-to-browse
- Selected file shows in a `<Badge>` with filename
- Field validation errors display correctly
- Form submission works identically
- Keyboard accessibility is preserved (or improved — `useDropzone` handles it natively)
