# MR54: Backend — Change Existing Upload Endpoint to /files/upload/cover with manga/cover Prefix

## Title

Change the existing `POST /files/upload` endpoint to `POST /files/upload/cover` and update the Minio prefix from `uploads` to `manga/cover`.

## Description

The current file upload endpoint (`POST /files/upload`) is generic and stores files under the `uploads/` prefix in Minio. Since this endpoint is only used for manga cover uploads, change it to be cover-specific: update the route to `/files/upload/cover` and the Minio prefix to `manga/cover`.

No new controller or endpoint is created — the existing endpoint method in `FileController` is modified in place. The `DELETE /files/*key` endpoint is unaffected.

## Requirement

- In `FileController` (`backend/src/modules/file/file.controller.ts`):
  - Change `@Post('upload')` to `@Post('upload/cover')`
  - Change the prefix argument in `fileService.upload('uploads', ...)` to `fileService.upload('manga/cover', ...)`
- Validation stays the same: image only (jpeg, png, webp, gif), max 10MB
- Response format stays the same: `{ key, url }`
- `DELETE /files/*key` endpoint must remain unchanged

## Acceptance Criteria

- [ ] `POST /files/upload/cover` accepts `multipart/form-data` with field `file`
- [ ] File is validated: image only (jpeg, png, webp, gif), max 10MB
- [ ] Stored under `manga/cover/<uuid>.<ext>` in Minio
- [ ] Returns `{ key, url }` in the same format as before
- [ ] `DELETE /files/*key` still works unchanged
- [ ] `cd backend && npx tsc --noEmit` passes with 0 errors
