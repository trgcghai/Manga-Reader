# MR97: Add batch import entry point to manga detail page

## Title

Add "Batch Import" button to the manga detail page that opens `BatchImportDialog`.

## Description

The manga detail page shows manga information and lists chapters. A new "Batch Import" button is added to the page header or the chapters section header to open the `BatchImportDialog`.

### Placement

The button should be placed in the page's action area, near (or alongside) the existing "Add Chapter" button. On the manga detail page, the `AddChapterDialog` is typically opened from a button in the page header or the chapters section header. The "Batch Import" button sits next to it.

### Behavior

1. Clicking "Batch Import" opens `BatchImportDialog`
2. The dialog receives `mangaId` from the current route
3. The button is disabled while the manga detail is loading (to prevent race conditions)

### Implementation

The integration is minimal — just add a `<Button>` and a `<BatchImportDialog>` to the manga detail page, likely in the route component at `frontend/src/routes/manga/$id.tsx` or wherever the manga detail is rendered.

No new route or page is needed.

### Dependencies

- `BatchImportDialog` from MR96
- `Button` from `#/components/ui/button`
- Existing manga detail route component

## Requirement

- "Batch Import" button visible on the manga detail page
- Opens `BatchImportDialog` on click
- Button disabled while page is loading
- `cd frontend && npm run check` passes with 0 errors

## Acceptance Criteria

- [ ] "Batch Import" button added to manga detail page near "Add Chapter" button
