# MR90: Backend ZIP extraction and Excel parsing utility for bulk import

## Title

Create ZIP extraction and Excel parsing utility for bulk chapter/translation import.

## Description

The bulk import flow accepts a single `.zip` file containing an Excel spreadsheet (`.xlsx`) and organized CBZ/ZIP files. A utility is needed to handle the extraction and parsing before the import service processes the rows.

### ZIP structure expected

```
import.zip
├── chapters.xlsx
└── files/
    ├── ch01/
    │   ├── en.cbz
    │   └── vi.cbz
    ├── ch02/
    │   └── en.cbz
    └── ...
```

### Utility responsibilities

1. **Extract ZIP to a temp directory**: Use `adm-zip` (or Node built-in `zlib`/`fs`) to extract the uploaded ZIP to a temporary folder. Clean up after import completes (or on failure).

2. **Read the Excel file from within the ZIP**: Locate `chapters.xlsx` (or the first `.xlsx` file if not found by exact name) in the extracted directory. Parse it using the existing `xlsx` package.

3. **Provide access to extracted files by relative path**: Given a `filePath` value from an Excel row (e.g., `files/ch01/en.cbz`), return the buffer or file path for uploading to MinIO.

4. **Error handling**:
   - ZIP does not contain any `.xlsx` file → throw `BadRequestException`
   - Referenced file path in Excel row does not exist in extracted files → report per-row error (do not abort entire import)
   - ZIP extraction fails (corrupted archive) → throw `BadRequestException`

### Implementation

- Create `backend/src/modules/manga/utils/zip-extractor.util.ts` (or a service if injection is needed)
- The utility should be stateless (receives buffer, returns structured data, cleans up)
- Return type:
  ```typescript
  interface ExtractedImport {
    rows: Record<string, string>[];  // parsed Excel rows
    readFile: (filePath: string) => Buffer | null;  // read extracted file by relative path
    cleanup: () => void;  // delete temp directory
  }
  ```

### Dependencies

- `xlsx` is already installed (`backend/package.json` has `"xlsx": "^0.18.5"`)
- `adm-zip` should be installed for ZIP extraction (lightweight, no native deps)
- Or use Node built-in `zlib` + `tar-stream` — but `adm-zip` handles `.zip` natively

### Changes needed

1. Install `adm-zip` package as a production dependency
2. Create `backend/src/modules/manga/utils/zip-extractor.util.ts`
3. Create `ExtractedImport` interface
4. Implement `extractZip(buffer: Buffer): ExtractedImport` function
5. Handle errors: missing Excel, corrupted ZIP, cleanup on failure
6. Add unit tests for the utility

## Requirement

- Parses the `.xlsx` file from within the ZIP into rows
- Provides a `readFile` function to retrieve extracted file buffers by relative path
- All temp files are cleaned up after the import finishes or on error
