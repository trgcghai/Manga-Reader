# MR23: Reader Progress Persistence

## Title
Remember the last read page per chapter.

## Description
Persist reader progress so the app can restore the last opened page when a reader returns to the same chapter later.

## Requirement
- Store the last read page for each chapter
- Restore saved progress when reopening a chapter
- Update progress as the reader moves through pages
- Keep progress storage local to the app environment

## Acceptance Criteria
- [ ] The last read page is saved for each chapter
- [ ] Reopening a chapter restores the saved page
- [ ] Progress updates as the reader changes pages
- [ ] Progress works without any network dependency

## Estimate Point
5
