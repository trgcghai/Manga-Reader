# MR37: Manga Table Filtering

## Title

Add filtering capabilities to manga table.

## Description

Allow users/admins to filter manga list based on common criteria for faster discovery and management.

## Requirement

- Filter by title
- Filter by author
- Filter by genre
- Filter by status (ongoing/completed)
- Filters should work well on mobile

## Acceptance Criteria

- [ ] User can filter manga list by title
- [ ] User can filter by author and genre
- [ ] Multiple filters can be combined
- [ ] Filtering works correctly on mobile viewports

## Estimate Point

3
