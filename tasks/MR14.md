# MR14: Language Configuration Per Manga

## Title
Manage languages for each manga.

## Description
Let an admin assign one or more languages to a manga so chapter metadata can be configured consistently for local ingestion.

## Requirement
- Allow adding a language to a manga
- Allow removing a language from a manga
- Surface the configured languages in the manga admin view
- Keep language choices scoped to the selected manga

## Acceptance Criteria
- [ ] Admin can add a language to a manga
- [ ] Admin can remove a language from a manga
- [ ] The manga detail view shows the configured languages
- [ ] Language configuration persists after refresh

## Estimate Point
5
