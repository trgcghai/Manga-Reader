# MR16: Chapter Folder Scan and Preview

## Title
Scan chapter folders and preview images before saving.

## Description
Add folder discovery logic that scans the selected chapter path, finds image files, and shows a preview before the chapter is persisted.

## Requirement
- Scan the selected folder for supported image files
- Display a preview of discovered images before save
- Limit preview behavior to local files only
- Handle missing or empty folders with a clear error state

## Acceptance Criteria
- [ ] Selecting a folder shows discovered chapter images before save
- [ ] The preview reflects the files found in the folder
- [ ] Empty or missing folders show a useful error message
- [ ] No chapter is saved until the user confirms the previewed scan result

5
