# MR55: Frontend — Update uploadFile API Call to Use /files/upload/cover

## Title

Change the `uploadFile` function in `fileApi.ts` to call `POST /files/upload/cover` instead of `/files/upload`.

## Description

After MR54 changes the backend route from `/files/upload` to `/files/upload/cover`, the frontend must match. Only the API URL needs to change — the `UploadFileResponse` type, the `useFileUpload` hook, and the page components (`new.tsx`, `$id.edit.tsx`) remain unchanged since they all consume `uploadFile` through `useFileUpload`.

## Requirement

- In `frontend/src/services/api/fileApi.ts`:
  - Change the URL in `axiosInstance.post()` from `'/files/upload'` to `'/files/upload/cover'`
- Optionally rename `uploadFile` to `uploadCover` for clarity
- `UploadFileResponse` type stays the same
- `useFileUpload()` hook stays the same
- Page components (`new.tsx`, `$id.edit.tsx`) stay the same — they already use `useFileUpload()`

## Acceptance Criteria

- [ ] `uploadFile()` calls `POST /files/upload/cover`
- [ ] `useFileUpload()` still works without changes
- [ ] Manga create page (`new.tsx`) uploads covers successfully
- [ ] Manga edit page (`$id.edit.tsx`) uploads covers successfully
- [ ] `cd frontend && npm run build` passes with 0 errors
