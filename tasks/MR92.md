# MR92: Backend controller endpoints for bulk chapter import

## Title

Add `POST /mangas/import-chapters` and `GET /mangas/import-chapters-template` endpoints.

## Description

Add two new endpoints to `MangaController` for the bulk chapter/translation import feature, following the same patterns as the existing manga import endpoints.

### Endpoints

#### `POST /mangas/import-chapters`

- Accepts a multipart file upload with field name `file`
- File must be `.zip` (content-type: `application/zip`)
- Maximum file size: 200MB (larger than the manga import since it contains CBZ files)
- Validates the file is present and is a ZIP
- Calls `ZipExtractor.extractZip(file.buffer)` to extract and parse the Excel
- Calls `ImportChapterService.import(rows, readFile)` to process all rows
- Calls `cleanup()` after import completes (in `finally` block)
- Returns `ImportResult { total, created, errors[] }`
- On error: `BadRequestException` for invalid file type, corrupted ZIP, or missing Excel

#### `GET /mangas/import-chapters-template`

Returns a `.zip` file containing the Excel template and an example folder structure so users can see exactly how to organize their files.

**ZIP contents:**
```
chapter-import-template.zip
├── chapters.xlsx
└── files/
    └── example/
        └── en.cbz          (empty placeholder ZIP)
```

**Excel file (`chapters.xlsx`):**
- Header row: `MangaId`, `Number`, `Title`, `Language`, `Translator`, `File`
- First data row with example values:
  - `MangaId`: `1`
  - `Number`: `1`
  - `Title`: `Chapter 1`
  - `Language`: `English`
  - `Translator`: `Scan Group A`
  - `File`: `files/example/en.cbz`

**Implementation:**
- Generate both the Excel file and an empty placeholder `.cbz` file in memory
- Use `adm-zip` to create a ZIP archive containing both the Excel and the folder structure
- Return as `StreamableFile` with content-type `application/zip`
- Disposition: `attachment; filename="chapter-import-template.zip"`

### Error handling

- No file uploaded → `400 Bad Request: "File is required"`
- File is not a ZIP → `400 Bad Request: "File must be a ZIP archive"`
- ZIP extraction fails → `400 Bad Request` with the specific error message
- Row-level errors are returned in `ImportResult.errors`, not as HTTP errors

### Implementation details

- Add new endpoints to the existing `MangaController`
- Inject `ImportChapterService` into the controller constructor
- Use `FileInterceptor('file')` from `@nestjs/platform-express`
- Configure the file interceptor with the 200MB limit:
  ```typescript
  new FileInterceptor('file', {
    limits: { fileSize: 200 * 1024 * 1024 },
  })
  ```
- The template generation uses `XLSX.utils.json_to_sheet` with the header row
