# MR27: Manga and Chapter Search

## Title
Search manga and chapters across the library.

## Description
Build search for manga by title, author, and genres, plus chapter search by number or title so readers can find content quickly.

## Requirement
- Search manga by title
- Search manga by author
- Search manga by genre
- Search chapters by number or title
- Update results as the query changes

## Acceptance Criteria
- [ ] Readers can search manga by title, author, and genre
- [ ] Readers can search chapters by number or title
- [ ] Search results update responsively as the user types
- [ ] Search stays local and offline

5
