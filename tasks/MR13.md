# MR13: Translator Management Per Manga

## Title
Manage translators for each manga.

## Description
Add per-manga translator management so an admin can assign, edit, and remove translators scoped to a specific manga record.

## Requirement
- Allow adding a translator to a manga
- Allow editing translator details for a manga
- Allow removing a translator from a manga
- Prevent duplicate translator entries for the same manga when applicable

## Acceptance Criteria
- [ ] Admin can add a translator to a manga from the UI
- [ ] Admin can edit translator information for that manga
- [ ] Admin can remove a translator from that manga
- [ ] Translator changes persist through the API and reload correctly

## Estimate Point
5
