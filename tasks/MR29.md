# MR29: Favorites

## Title
Mark and filter favorite manga.

## Description
Add a favorites system so readers can save manga they want to return to and filter the library to favorites only.

## Requirement
- Allow marking manga as favorite
- Allow removing manga from favorites
- Support filtering the library to favorites
- Persist favorites locally

## Acceptance Criteria
- [ ] Readers can mark a manga as favorite
- [ ] Readers can remove a manga from favorites
- [ ] The library can be filtered to favorite items
- [ ] Favorite state persists after reload

3
