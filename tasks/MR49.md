# MR49: File Controller

## Title

Create a file controller with REST endpoints for file upload and retrieval.

## Description

Build a REST API controller (`/files`) that exposes endpoints for uploading and serving files stored in Minio. This enables the frontend and admin workflows to upload manga covers, chapter pages, and other assets.

## Requirement

- Create `backend/src/modules/file/file.controller.ts`
- `POST /files/upload` — accept multipart file upload, store in Minio, return the file key
- `GET /files/:key` — stream a file from Minio with correct `Content-Type`
- `DELETE /files/:key` — delete a file from Minio
- Use `FileInterceptor` from `@nestjs/platform-express` for the upload endpoint
- Validate file type (accept only images: jpg, png, webp) and size limits
- Register the controller in the file module
- Register the file module in `app.module.ts`

## Acceptance Criteria

- [ ] `POST /files/upload` accepts image uploads and returns file key/metadata
- [ ] `GET /files/:key` streams the file with correct MIME type
- [ ] `DELETE /files/:key` deletes the file
- [ ] Non-image file types are rejected with a clear error
- [ ] File size exceeding limit is rejected
- [ ] Routes are registered and accessible
