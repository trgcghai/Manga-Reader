# MR57: Backend — Add POST /files/upload/translation Endpoint for CBZ Upload

## Title

Add POST /files/upload/translation endpoint with mangaId + chapterNumber payload, CBZ-only validation, 15MB limit, and prefix /manga/{mangaId}/chapter/{chapterNumber}/translations.

## Description

A new endpoint is needed to upload CBZ translation files for chapters. The endpoint must accept a multipart form with a single CBZ file plus `mangaId` and `chapterNumber` as required fields. The file is stored in Minio under the path `/manga/{mangaId}/chapter/{chapterNumber}/translations/`.

### Changes needed

1. **Constants** — Add CBZ MIME types (`application/vnd.comicbook+zip`, `application/zip`) to a new constant or reuse existing pattern.

2. **DTO** — Create `UploadTranslationFileDto` with `mangaId` (number, required) and `chapterNumber` (number, required) decorated with `@IsNumber()` and `@IsNotEmpty()`.

3. **FileService extension** — Add `'application/zip': 'cbz'` and `'application/vnd.comicbook+zip': 'cbz'` to `EXT_MAP` so the uploaded file gets the `.cbz` extension.

4. **Endpoint** — Add `@Post('upload/translation')` to `FileController`:
   - Accept `file` via `FileInterceptor('file')`
   - Accept body via `@Body() dto: UploadTranslationFileDto`
   - Validate file: CBZ only (regex `application/zip|application/vnd.comicbook+zip`), max 100MB, single file
   - Construct prefix: `/manga/${dto.mangaId}/chapter/${dto.chapterNumber}/translations`
   - Call `fileService.upload(prefix, file.buffer, file.mimetype)`

## Requirement

- Create `backend/src/modules/file/dto/uploadTranslationFile.dto.ts` with `mangaId` and `chapterNumber` as required numbers
- Add CBZ MIME type constant to `backend/src/common/constants/chapter.constant.ts` or a new constant file
- Extend `EXT_MAP` in `FileService` to map ZIP MIME types to `'cbz'`
- Add `POST /files/upload/translation` to `FileController`
- Validate the file as CBZ only (max 100MB, single file) via `ParseFilePipe`
- Construct the Minio prefix dynamically: `/manga/{mangaId}/chapter/{chapterNumber}/translations`

## Acceptance Criteria

- [ ] `POST /files/upload/translation` accepts a multipart form with `file` (CBZ), `mangaId` (number), `chapterNumber` (number)
- [ ] Rejects request with 400 if `mangaId` or `chapterNumber` is missing or not a number
- [ ] Rejects file larger than 100MB with 400
- [ ] Rejects non-CBZ files with 400
- [ ] Stores file under `/manga/{mangaId}/chapter/{chapterNumber}/translations/{uuid}.cbz` in Minio
- [ ] Returns `{ key, url }` on success
- [ ] `cd backend && npm test` passes (all tests green)
