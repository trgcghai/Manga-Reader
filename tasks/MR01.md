# MR01: Backend Project Setup & Health Endpoint

## Description
Initialize and configure the NestJS backend project structure, ensure TypeScript, ESLint, and Prettier are properly set up, and add a health check endpoint to verify the server is running.

## Requirements
- NestJS project scaffolded with `@nestjs/cli`
- TypeScript configured (`tsconfig.json`)
- ESLint and Prettier configured and passing
- Health check endpoint at `GET /health`
- Server runs on port 3001 by default
- `npm run start:dev` starts the server in watch mode
- Dockerfile for backend builds successfully

## Acceptance Criteria
- [ ] `npm run start:dev` starts the backend without errors
- [ ] `GET /health` returns `{ "status": "ok" }` with 200 status
- [ ] `npm run lint` passes with zero warnings/errors
- [ ] `npm run format` formats all `.ts` files correctly
- [ ] Docker build succeeds with `docker build -t backend .`
- [ ] `backend/package.json` scripts work as documented

## Estimate
3 points
