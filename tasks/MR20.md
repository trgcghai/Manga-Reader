# MR20: Public Library Page

## Title
Browse manga from a public library page.

## Description
Build the public-facing library page that shows available manga in a grid or list with cover art so readers can discover titles locally.

## Requirement
- Display manga entries on a public library page
- Show cover images where available
- Support a grid or list layout that is easy to scan
- Keep the page usable without authentication or internet access

## Acceptance Criteria
- [ ] Readers can open a public library page
- [ ] Manga entries are visible with cover art when present
- [ ] The page presents manga in a readable grid or list
- [ ] The page works entirely with local data

## Estimate Point
5
