# MR20: Public Library Page

## Title
Browse manga from a public library page — replaces the current `/` index route placeholder.

## Description
Build the public-facing library page showing available manga in a responsive cover grid with pagination. Readers can browse titles and see cover art. No authentication required. Clicking a manga does nothing yet (detail page is a future task).

## Requirements

### Route
- Replace the existing `/` route (`frontend/src/routes/index.tsx`) — currently just shows "Hello, Manga Reader!"
- No layout wrapper needed for now (no public header/nav)

### Data & API
- Fetch manga list via existing `useMangaList(page, limit)` hook from `#/hooks/useManga`
- Hook calls `GET /mangas?page={page}&limit={limit}` — returns `PaginatedResponse<MangaResponse>`
- `MangaResponse` fields to use:
  - `coverPath` — use directly as `<img>` `src` (this is a URL/path, not a local file)
  - `title`
  - `authors` (for subtitle)
  - `status` (for badge)

### States
- **Loading**: Show a grid of skeleton cards (use `Skeleton` component) matching the grid layout
- **Empty**: Show `Empty` component with `Library` / `BookOpen` icon when no mangas exist
- **Error**: Show `ErrorDisplay` component when fetch fails

### Cover Grid Layout
- Responsive CSS grid:
  - 2 columns on mobile (`sm:grid-cols-2`)
  - 3 columns on tablet (`md:grid-cols-3`)
  - 4 columns on desktop (`lg:grid-cols-4`)
- Each card:
  - Aspect-ratio cover image (e.g. `aspect-[3/4]`) with `object-cover`
  - When `coverPath` is missing/null, show a placeholder icon (e.g. `BookOpen` from lucide) centered in the card
  - Title below the cover, truncated to 2 lines
  - Status badge (reuse `Badge` component with same variant logic as admin detail page)
  - Author names as secondary text, truncated to 1 line

### Pagination
- Place pagination below the grid using existing `Pagination` component from `#/components/ui/pagination`
- Wire to page state; re-fetch on page change

### Click Behavior
- Cards are not clickable / have no navigation (detail page is future MR)
- Entire page works offline with local data only

### Existing Components to Reuse
- `Skeleton` — cover card skeleton placeholders
- `Empty`, `EmptyHeader`, `EmptyMedia`, `EmptyTitle` — empty state
- `ErrorDisplay`, `ErrorTitle`, `ErrorDescription` — error state
- `Pagination` — page navigation
- `Badge` — status indicator

## Acceptance Criteria
- [ ] `/` route shows a responsive grid of manga cover cards
- [ ] Covers render from `coverPath` when present; placeholder icon when absent
- [ ] Shows loading skeleton grid while data fetches
- [ ] Shows empty state when no mangas exist
- [ ] Shows error state on fetch failure
- [ ] Pagination controls work and re-fetch on page change
- [ ] Works entirely with local data, no auth required
