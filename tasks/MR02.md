# MR02: Frontend Project Setup & App Shell

## Description
Initialize and configure the TanStack Start frontend project, set up TypeScript, ESLint, Prettier, Tailwind CSS, and create the basic app shell with routing.

## Requirements
- TanStack Start project scaffolded
- TypeScript configured (`tsconfig.json`)
- ESLint and Prettier configured and passing
- Tailwind CSS v4 integrated
- Root route (`__root.tsx`) with basic layout
- Home route (`index.tsx`) renders a placeholder
- Server runs on port 3000 by default
- `npm run dev` starts the frontend in watch mode
- Dockerfile for frontend builds successfully

## Acceptance Criteria
- [ ] `npm run dev` starts the frontend without errors
- [ ] Home page renders with basic layout and Tailwind styles
- [ ] `npm run lint` passes with zero warnings/errors
- [ ] `npm run format` formats all files correctly
- [ ] Docker build succeeds with `docker build -t frontend .`
- [ ] `frontend/package.json` scripts work as documented

## Estimate
3 points
