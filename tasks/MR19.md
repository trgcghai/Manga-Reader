# MR19: Admin Panel Layout

## Title
Separate the admin panel layout from reader pages.

## Description
Create a distinct admin layout so content management screens are clearly separated from the reader experience.

## Requirement
- Provide a dedicated admin layout shell
- Keep reader routes visually separate from admin routes
- Make navigation between admin and reader areas clear
- Preserve the local-only product structure

## Acceptance Criteria
- [ ] Admin routes render inside a dedicated admin layout
- [ ] Reader pages remain outside the admin shell
- [ ] Navigation clearly shows the user is in the admin area
- [ ] The layout works on the existing frontend app shell
