# MR15: Chapter Creation Form

## Title
Create chapters from a local folder path.

## Description
Build the chapter creation form with folder path input plus language and translator selection so admins can register a new chapter from local files.

## Requirement
- Accept a local folder path for chapter ingestion
- Require language selection before save
- Require translator selection before save
- Submit chapter metadata with folder path, language, and translator

## Acceptance Criteria
- [ ] Admin can enter a folder path for a chapter
- [ ] Admin can select a language for the chapter
- [ ] Admin can select a translator for the chapter
- [ ] Chapter save stores the metadata required for local ingestion

## Estimate Point
5
