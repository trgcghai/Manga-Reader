# MR17: Chapter List With Metadata Labels

## Title
Show chapter lists with language and translator labels.

## Description
Add a chapter list per manga so admins can review stored chapters with their language and translator metadata.

## Requirement
- Display chapters grouped under the selected manga
- Show language labels for each chapter
- Show translator labels for each chapter
- Keep chapter ordering stable and readable

## Acceptance Criteria
- [ ] Admin can view a chapter list for a manga
- [ ] Each chapter row shows its language label
- [ ] Each chapter row shows its translator label
- [ ] The list updates after a new chapter is saved

## Estimate Point
3
