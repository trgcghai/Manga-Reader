# MR10: Docker Compose Dev Environment

## Title
Wire up the local dev stack with Docker Compose.

## Description
Create a repeatable local development environment that runs the backend, frontend, PostgreSQL, MongoDB, and Redis together with persistent volumes.

## Requirement
- Compose services for backend, frontend, PostgreSQL, MongoDB, and Redis
- Map persistent volumes for database data
- Mount source folders for live reload development
- Ensure ports do not conflict between services
- Keep the stack local-only

## Acceptance Criteria
- [ ] `docker compose up --build` starts all services successfully
- [ ] PostgreSQL data persists across restarts
- [ ] MongoDB data persists across restarts
- [ ] Redis data persists across restarts
- [ ] Backend and frontend source mounts support code changes without rebuilding images
- [ ] Service ports are documented and reachable locally
